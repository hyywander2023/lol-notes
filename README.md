Obsidian 格式的个人 LoL 笔记库。内容来自两个源：OPgaming 课程体系（判断与流程）＋ studyliang 实战教学（手上动作与英雄精读），并以 2026 赛季规则总纲校准。

**289 篇笔记**：结论卡做判断，参考卡做强查，英雄精读卡做对位。

## 起步

用 Obsidian 打开本目录，从 `00_知识库入口/总库地图.md` 开始。

## 写笔记的约定

```yaml
---
tags:        # 位置/主题 + 阶段
aliases:     # 搜索别名（含英文名与常见绰号）
适用版本: 2026赛季（26.x）
源: OPgaming《课程名》  # 或 studyliang《视频名》+ 日期
---
```

正文：**结论 → 判据/操作（表格优先）→ 关联（双链）**。

课程旧数值与 2026 总纲冲突时，保留原理、按 2026 校准，并标 `> ⚠️ 版本差异`。
