## 七、学习路径

**第一轮（打基础，按顺序）**

```
兵线刷新与小兵构成 → 小兵仇恨机制 → 抢二 → 快推线 → 控线冻结
→ 反弹线的形成条件 → 支援前先推线
```

**第二轮（减少送头）**

```
第一性原理 只做能推塔的事 → 塔前有兵线不支援 → 经济要及时花掉
→ 单杀前先算清线能力 → 残血单杀先推线进塔 → 死亡时间 只在低风险窗口做事
```

**第三轮（赢团）**

```
阵容三流派克制环 → 开团前的四个前置条件 → 控制链顺序
→ 集火目标要一致 → C位安全距离 → 团战止损
```

**第四轮（位置专精）**

进入对应位置 MOC，按「前期 → 中期 → 后期 → 团战 → 速记」读。

**第五轮（对位）**

进 [[英雄职业 MOC]]，按对面的职业找「打它」。

## 九、笔记规范

每篇笔记的 frontmatter 固定四个字段：

```yaml
---
tags:        # 位置/主题 + 阶段，用于筛选
aliases:     # 别名，让搜索命中不同叫法
适用版本: 2026赛季（26.x）
源: OPgaming《课程名》  # 可溯源到原始课程
---
```

正文结构：**结论（引用块）→ 判据/操作（表格优先）→ 关联（双链）**。

数值类内容与课程冲突时，保留原理、按 2026 校准，并加：

```
> ⚠️ 版本差异：课程为旧数值，已按 2026 赛季更新。
```

**例外**：`40_英雄职业` 是参考卡，允许长表格，不给字数上限。
