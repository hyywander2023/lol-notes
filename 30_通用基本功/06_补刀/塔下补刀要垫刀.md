# 塔下补刀要垫刀

> 结论：塔下补刀别按理论次数算——先垫一次普攻再补，炮车看实际血量。

## 原理

防御塔先把兵打到你的斩杀线，你再补最后一击。不同兵种需要的次数不同：

| 兵种 | 处理逻辑 |
| --- | --- |
| 近战兵 | 让塔先磨几下，到位再补 |
| 远程兵 | 满血时通常要先垫一次普攻，否则塔打完你补不上 |
| 炮车 | 塔要磨很多下，别照理论值，盯着实际血量 |

## 塔的攻击顺序

防御塔优先攻击离它「目标选择中心」最近的小兵。看小兵站位就能预判下一刀打谁，提前站好补刀位置。

## 执行

- 远程法师尤其要垫刀；ADC 装备成型后可以省掉这一步。
- 炮车快没血时提前起手，别等塔打完再反应。
