# 高风险补刀要算账

> 结论：这一刀的钱不够赔血就放掉——漏刀正常，被抓死才亏。

## 决策表

| 情况 | 决策 |
| --- | --- |
| 血量健康、能安全补 | 补 |
| 要挨一下敌方攻击，且这刀不关键 | 放掉 |
| 补炮车要吃控制 | 通常放，除非能顺手换血赚回来 |

## 判断要素

- 自己当前血量。
- 敌方英雄的威胁范围。
- 兵线位置（塔下 / 河道 / 敌方塔前）。

## 参考标尺

用「一瓶血的钱能换回多少血」做参照：为了一个不值钱的兵，赔上半管血甚至一条命，永远是亏的。对线期漏刀 20%–30% 属正常，关键炮车优先保。

## 执行

- 观察敌方补刀动作时同步补刀，这是最安全的窗口。
- 漏了就漏了，别用连续莽撞去追回那一刀。
