# 补刀的本质：只算最后一击

> 结论：只有最后一击才给钱——把兵压到「你的攻击力高于剩余血量」再出手。

## 最后一击

- 补刀 = 对小兵造成最后一下，才拿到全额金币。
- 普通小兵护甲魔抗为 0，你对它的伤害约等于你的攻击力数值。
- 左键点小兵，左上角显示精确血量，比看血条准——补炮车时尤其有用。

## 先普攻后技能

| 顺序 | 结果 |
| --- | --- |
| 先普攻压到斩杀线，再放技能 | 阈值高、容错大，不容易漏 |
| 先放技能 | 容易伤害溢出，兵没死又没技能补 |
| 炮车残血 | 可破例优先用技能补 |

## 设置

- 关掉自动攻击（ESC → 游戏 → 玩法）：补完一个会自动找下一个目标，导致推线过快或漏刀。
- 用 A 键 + 左键比纯右键稳；可关「显示攻击距离」减少白圈闪烁。
