# 视野是全队的事

> 结论：地图全黑不是辅助一个人的锅——按区域分工，每人至少备一个真眼。

## 视野是共享的

五人视野完全互通，队友看到的就是你看到的。

| 来源 | 说明 |
| --- | --- |
| 单位 | 英雄、小兵、防御塔（防御塔提供真实视野） |
| 设备 | 饰品眼、控制守卫 |
| 技能 | 部分英雄技能（如寒冰 E） |

所以「我没看到」往往等于「我们队没人去过」。

## 责任按区域切

| 区域无视野 | 谁负责 |
| --- | --- |
| 上路区域 | 上单 |
| 中路区域 | 中单 |
| 下路区域 | 下路组合 |
| 自家野区 | 中野辅（上半区上中野，下半区中辅野） |

## 执行

- 每人身上常备真眼，覆盖关键区域，不是只靠辅助。
- 判断顺序：先看哪块黑了 → 对号入座 → 补一个眼，而不是先骂人。
- 这是全队的责任，不是某个位置被抓的借口。
