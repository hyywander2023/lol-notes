# 草丛卡视野与攻击暴露

> 结论：想脱战就进草，但出手前先想好——在草里攻击会短暂暴露你。

## 草丛规则

| 行为 | 结果 |
| --- | --- |
| 人在草外 | 看不到草内，即便周围有视野 |
| 进草 | 断小兵仇恨、断对手视线（见 [[小兵仇恨机制]]） |
| 草内攻击 / 放技能 | 短暂暴露自身位置 |

## 两个用法

**脱仇。** 上单在草丛边缘 A 兵后立刻进草，小兵失去目标，不会转头打你。这是低成本换血的前提。

**卡视野。** 站在草里让对手丢失目标，等他技能空放或走位靠前，再出手。进出草丛可以反复重置对方的预判。

## 执行要点

- 草丛是双方必争的视野点：谁先插眼谁掌握信息差。
- 在草里出手会被看到，所以用草丛阴人时，打完要么撤、要么补控制。
- 别在对手有眼的情况下躲草等他——你以为卡了视野，其实一直被看。
