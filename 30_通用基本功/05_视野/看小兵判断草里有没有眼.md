# 看小兵判断草里有没有眼

> 结论：不用扫描也能探眼——小兵朝你跑就是有眼，径直走过就是没眼。

## 原理

小兵只会攻击视野内的敌方单位。你站在草里：

| 草内情况 | 小兵表现 |
| --- | --- |
| 有敌方眼位 | 看到你，把你当最近目标，朝你跑来 |
| 没有眼位 | 看不到你，径直走过 |

## 用法

- 位置：上路敌方一塔旁草、下路敌方一塔最近草，一波兵靠近时站进靠前的草丛观察。
- 蹲人前先看小兵走向，判断草里有没有眼，再决定要不要换位置或等扫描。
- 不用浪费扫描，也不用真眼，零成本排除一个盲区。

## 边界

- 这招只对「草内是否有眼」有效，判断不了眼是谁放的、还能存多久。
- 小兵在攻击防御塔时会忽略仇恨信号，这时候别用这个结论。
- 想进一步确认，点击眼位看单位框，能看到是谁插的，反推他来过没有。
