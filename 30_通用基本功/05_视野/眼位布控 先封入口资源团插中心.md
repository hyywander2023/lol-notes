# 眼位布控：先封入口，资源团插中心

> 结论：先用两个眼封住野区入口，再压对面野区；资源团把眼插龙坑中心，别插坑口。

## 进攻眼与防守眼

| 类型 | 位置 | 作用 |
| --- | --- | --- |
| 防守眼 | 己方野区入口（上/下半区各两个关键点） | 封锁入口，敌人进来必被发现 |
| 进攻眼 | 敌方野区、河道 | 看打野动向、掌握游走路线 |

真眼 + 假眼配合，一个照路一个反隐。优势方把眼位前压到敌方野区，给对面打野压力——打野舒服了，线上才舒服。

## 无效眼位

草丛边缘那种「看起来防 Gank」的眼，前期几乎没有作用。中路生存环境好，已知打野位置时防 Gank 眼完全多余。要插就插河道草、野区入口这类高信息价值的位置。

## 资源团

| 位置 | 目的 |
| --- | --- |
| 龙坑内真眼 | 防抢龙 |
| 龙坑中心（不是坑口） | 插坑口会留下两侧盲区 |
| 身后 / 两侧 | 防绕后、防包夹 |

**顺序：先扫描清对面真眼，再由打野或辅助把眼插到坑中心。** 大龙同理，坑内真眼 + 上方路口 + 侧翼草丛。
