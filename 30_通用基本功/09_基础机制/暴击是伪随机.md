# 暴击是伪随机

> 结论：连续没暴击就快到高概率窗口——把「幸运值」攒到打架前。

## 机制

暴击不是纯随机，而是马尔可夫链式的伪随机：实际暴击率围绕显示值动态调整，连续未暴击会提高下次概率，刚暴击后暂时降低。这是机制，不是 bug，见 [[机制不是bug]]。

## 用法

| 场景 | 动作 |
| --- | --- |
| 打架前 | 先 A 小兵或野怪攒「幸运值」，连着没暴击时开打 |
| 对线期 | 注意对手的暴击积累，躲开他的高概率窗口 |
| 配装 | 按 2026 暴击伤害 200% 衡量收益，别套旧版数值 |

## 边界

别把「刚才暴击了」当成「接下来不容易暴击」的绝对依据，概率是动态调的。核心是观察连续未暴击的次数，把它当成可管理的资源。
