# 阵容三流派克制环

> 结论：开团之前先认清双方是哪种流派。你的开团方式错了，再好的操作也是送。

## 克制关系

```
强开流 ──克──> Poke 流
   ↑                │
   │                │
   └── 克 ── 反打流 ←┘
```

- **强开流怕反打流**：你先进场，对面技能全是反手，你等于替他开团
- **反打流怕 Poke 流**：他等你先进，你不进他就一直消耗，血线被磨干
- **Poke 流怕强开流**：他手长但脆，被抓到一次就崩

## 怎么用

| 我是 | 对面是 | 打法 |
| --- | --- | --- |
| 强开 | Poke | 别拖，找一次机会直接开，越拖越亏 |
| 强开 | 反打 | 不要先手。让兵线/资源逼他们动，抓他失误 |
| 反打 | 强开 | 主动卖破绽，等他开进来再打 |
| 反打 | Poke | 强行找机会，不能被消耗到残血再打 |
| Poke | 强开 | 保持距离，视野先做，站位永远比对面远一格 |
| Poke | 反打 | 慢慢磨，不要给对面开团的机会 |

## 判断阵容属于哪一流派

看技能组，不看英雄名字：

- 有 2 个以上先手硬控/突进 → 强开流
- 技能以「等对方进来再打」为主（布隆、加里奥、锤石、皎月反手）→ 反打流
- 主要输出手段是远距离消耗，缺少先手 → Poke 流
