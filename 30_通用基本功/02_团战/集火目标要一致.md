# 集火目标要一致

> 结论：五个人的伤害打三个人，等于没打。王者级选手和普通玩家最大的差别，是伤害「永远不分开」。

## 原则

同一时间，全队只打一个目标。打在谁身上不重要，重要的是**打在同一个身上**。

## 目标优先级

| 优先级 | 目标 | 说明 |
| --- | --- | --- |
| 1 | 走位失误的 C 位 | 最容易秒、收益最高 |
| 2 | 残血 | 快速减员，形成 5v4 |
| 3 | 最近的可打目标 | 打不到后排时，先打前排，不要绕 |

**不要为了打后排而穿过对方前排。** 打不到就不打，绕路的过程就是你被集火的过程。

## 下路的特殊要求

AD 和辅助必须打同一个目标。AD 打前排、辅助打后排，是最典型的火力分散。

## 特殊情况

- **佛耶戈**：先杀残血变身，比追 C 位收益高
- **孤立 C 位**：如果 C 位和队友脱节，先杀他队友，他一个人打不了团
