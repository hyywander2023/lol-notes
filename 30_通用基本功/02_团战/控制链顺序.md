# 控制链顺序：先稳定控，再技能，最后 AOE

> 结论：控制技能重叠是最常见的浪费。顺序错了，四个控只等于一个控。

## 正确顺序

```
① 稳定控（必中、指向性/低风险）
   ↓
② 非指向性技能（需要预判，靠①固定目标）
   ↓
③ AOE 控制/伤害（收尾，覆盖多人）
```

## 例子

| 组合 | 顺序 |
| --- | --- |
| 寒冰大招 + 岩雀岩突 | 先箭定住 → 再岩突，不用预判 |
| 牛头二连 + 岩雀岩突 | 二连击飞 → 岩突必中 |
| 韦鲁斯大招 + 萨勒芬妮 ER | 先锁链 → 再 ER 覆盖 |

## 常见错误

- **同时交两个硬控**：第二个控在第一个控的时间里被浪费
- **先交预判技能**：空了之后稳定控才跟上，等于白交
- **控制全空**：三个关键控（钩子、锁链、大招）全空，团战直接结束

## 自检

打完一波团，回放问自己：

1. 我的控制是不是在队友控制生效期间丢的？
2. 我的控制是不是浪费在了一个已经不能动的人身上？
3. 我有没有把控制留给"进来了但没被控住"的那个人？
