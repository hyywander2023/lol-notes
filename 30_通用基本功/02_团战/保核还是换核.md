# 保核还是换核

> 结论：己方 C 位肥，全队保他；己方 C 位废，全队去换对面的 C 位。中间状态才需要纠结。

## 决策表

| 己方 C 位发育 | 对方 C 位发育 | 打法 |
| --- | --- | --- |
| 好 | 一般 | 全力保核，前排挡刀，控制留给突进 |
| 差 | 好 | 换核，一切资源用来切对面 C 位，互换不亏 |
| 都差 | 都差 | 打前排、抢资源，别开团 |
| 都好 | 都好 | 看阵容流派（见 [[阵容三流派克制环]]） |

## 常见错误

**己方 AD 已经 0-5，全队还在保护他。** 这时候保护一个打不出伤害的人，等于保护一个尸体。

反过来，己方 AD 三件套在手，辅助还在追着对面法师打，也是浪费。

## 判断「肥」的标准

不是人头数，是**装备时间点**：

- 正常发育：8–10 分钟出第一件成装
- 领先：提前 2 分钟以上出第一件
- 落后：12 分钟还没出第一件
