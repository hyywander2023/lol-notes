# C 位安全距离

> 结论：C 位多站前 2–3 个身位，就是这波团输的直接原因。

## 判据

站位标准只有一条：**对面最远的突进手段够不到你。**

具体算法：

1. 找出对面威胁最大的突进/开团技能
2. 算出它的射程 + 位移距离
3. 你的站位必须在这条线外

## 输出原则

- 能打谁就打谁，不执着于打后排
- 活着才有输出，数据不重要
- 不贪人头（K 头）导致前压
- 不为了补一个残血而走出安全区

## 常见失误

| 失误 | 后果 |
| --- | --- |
| 站位超出安全距离 2–3 个身位 | 被 AOE 一波带走 |
| 追击时阵型散开 | 被 1v4 反打 |
| 站在前排和后排之间 | 既不能输出也不能撤 |

## 前排的责任

前排卡住关键地形，后排才有安全距离。**前排不是去追人，是去占位置。** 前排一散，后排立刻暴露。
