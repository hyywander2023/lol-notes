# 团战止损：放弃救不了的人

> 结论：一个人被开到必死，剩下四个人要做的是走，不是救。

## 判断

问一句：**救他会不会让更多人死？**

| 情况 | 决策 |
| --- | --- |
| 被开的是前排，还有技能 | 救，前排就是用来吃伤害的 |
| 被开的是 C 位，位置深、无位移 | 不救，止损 |
| 对面已交完关键技能，能反打 | 救，这是反打窗口 |
| 对面技能全在，人数还多 | 不救，立刻走 |

## 止损后的正确动作

不是站着看队友死，而是：

1. 立刻拉开，保住剩余人力
2. 找等价资源（对面在打龙，你去推塔/清野/吃线）
3. 记录对面交掉的召唤师技能，下一波用

## 反例

典型崩盘：一个人被抓 → 两个人去救 → 三个人死 → 掉男爵 → 输。

**止损的价值不在于这波少死一个，而在于不让一次失误变成一次团灭。**
