# 骗关键技能

> 结论：比对手多一个技能就赢换血——用假动作让他先交，再打。

## 四种骗法

| 方法 | 操作 |
| --- | --- |
| 主动诱骗 | 位移逼近逼对手交关键技能（机器人 Q、阿狸 E），站在兵线外引技能、保持能躲回兵后的距离 |
| 走位规避 | 在技能边缘反复试探，精准躲掉后趁 CD 压制 |
| 假装补刀 | 做出补刀动作，最后一刻取消后撤；优先拿远程兵做，成本低 |
| 小兵死亡瞬间 | 兵快死时突然出招（盲僧 Q 接惩戒、锤石 Q 残血兵），命中率最高 |

## 纪律

- 同一种骗法别重复用，对手会适应。
- 技能空放等于失去主动权，宁可晚一秒也别乱交。
- 骗到技能后立刻打，CD 窗口就那么长。

## 抓补刀僵直

对手普攻小兵的前摇阶段无法移动，这时上去免费普攻或放指向技能。口诀：**他补刀就挨打，不补刀就漏兵。**
