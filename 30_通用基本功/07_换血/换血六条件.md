# 换血六条件

> 结论：兵线、等级、技能、血量、召唤师技能、打野位置——占得越多才换，己方损耗小于对方才算赚。

## 六项优势

| 条件 | 优势判定 |
| --- | --- |
| 兵线 | 己方兵更多，或对手站位差 |
| 等级 | 己方更高，多技能、多属性 |
| 技能 | 己方可用的更多，或对手正在 CD |
| 生命值 | 己方血量更高 |
| 召唤师技能 | 对手在 CD 而己方可用 |
| 打野位置 | 己方打野在附近，或敌方打野已暴露 |

## 黄金法则

己方消耗 < 对方消耗，才叫赚。换血失败不是「小亏」，而是被迫回城补给，把压力转嫁给队友。

## 按英雄调

爆发型（卢锡安）快速压进斩杀线，即使换血亏，进斩杀线就是赚；持续型（EZ）靠多轮消耗；回复型（吸血鬼、扎克）先打断回复条件再换。

## 打野判断

对手反常走位可能是打野埋伏。不确定敌方打野在哪，就别做大换血；己方打野在场时，就算小亏也要换，给他创造 gank 机会。
