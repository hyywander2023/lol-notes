# 鞋子选择

> 结论：鞋子按「对面主要伤害类型 + 控制量」选，不是按英雄选。

## 判断

| 对面情况 | 鞋子 |
| --- | --- |
| AD 伤害为主 | 护甲鞋 |
| AP 伤害为主 / 控制多 | 魔抗韧性鞋 |
| 靠普攻输出（射手） | 攻速鞋 |
| 靠技能打伤害（法师） | 法穿鞋 |
| 靠技能循环（战士/法师） | 技能急速鞋 |
| 需要跑图/游走 | 移速鞋 |

## 时机

- 大多数情况第一件成装之后再升级鞋子
- 需要频繁游走的英雄（中单、辅助）可以提前出
- 部分打法会完全跳过鞋子换输出（如穿甲流女枪前期不出鞋）

## 2026 相关变化

> ⚠️ 2026 赛季中单分路任务奖励包含「鞋子免费升三级」，射手的分路任务可以把鞋子移到任务栏位空出装备格。要不要提前买鞋，需要按分路任务进度判断。
