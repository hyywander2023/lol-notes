# 生命与抗性搭配

> 结论：每 1 点抗性让「有效生命值」+1%，所以生命和抗性必须一起堆，只堆一种效率低。

## 减伤公式

```
实际承受比例 = 100 ÷ (100 + 抗性)
```

| 抗性 | 承受伤害 |
| --- | --- |
| 50 | 约 67% |
| 100 | 50% |
| 200 | 约 33% |

## 为什么必须搭配

- 只有生命没抗性：对方穿透一出，血量像纸
- 只有抗性没生命：抗性放大的是一个很小的基数
- 生命 × 抗性 = 有效生命，两者相乘才有效

## 实战判断

| 情况 | 优先 |
| --- | --- |
| 对面有百分比穿透（打坦克装） | 堆生命，抗性收益被削减 |
| 对面是固定穿透（刺客） | 堆抗性，能吃掉大量固定穿透 |
| 对面全队同一种伤害类型 | 堆对应抗性，收益极高 |
| 对面混伤 | 生命优先，抗性均衡 |

## 阵容层面的推论

对面全 AD 时堆护甲收益极高，全 AP 时堆魔抗收益极高。这也是为什么阵容需要物理与魔法伤害混合——单一伤害类型会被一件装备废掉。

## 版本提示

> ⚠️ 公式是长期不变的原理；具体装备的抗性/生命数值随版本变化。
