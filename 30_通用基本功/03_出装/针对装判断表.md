# 针对装判断表

> 结论：对面有什么，你补什么。这张表比任何出装攻略都好用。

## 判断表

| 对面的问题 | 该补什么 | 典型装备 |
| --- | --- | --- |
| 回复/治疗多 | 重伤 | 死刑宣告系、莫雷洛秘典系、荆棘之甲 |
| 魔抗堆高 | 百分比法穿 | 虚空之杖 |
| 护甲堆高 | 百分比护甲穿透 | 多米尼克领主的致意 |
| 脆皮多 | 固定穿透/穿甲 | 幽梦、赛瑞尔达 |
| AP 爆发高 | 魔抗 + 护盾 | 水银之靴、自然之力、饮魔刀 |
| AD 爆发高 | 护甲 | 兰顿、冰霜之心、亡者的板甲 |
| 关键控制多 | 解控/韧性 | 水银饰带、水银弯刀、坚定 |
| 刺客突进 | 金身/复活 | 中娅沙漏、守护天使 |
| 需要开团抗伤 | 双抗 + 主动护盾 | 钢铁烈阳之匣 |

## 使用顺序

1. 先看对面谁最肥
2. 再看他的伤害类型/机制
3. 只补一件，不要三件都补（装备位有限）

## 常见误区

- **无脑堆抗性不堆生命**：抗性放大的是生命值，生命太低抗性收益也低（见 [[生命与抗性搭配]]）
- **对面一个回复怪就全队出重伤**：重伤不叠加，一个人出就够
- **对面 AP 多却只买魔抗斗篷**：斗篷只是散件，不解决问题
