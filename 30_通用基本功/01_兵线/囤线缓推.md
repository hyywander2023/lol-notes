# 囤线缓推（囤线）

> 结论：想越塔、想吃镀层，先攒 2–3 波兵一起推进去。

## 操作

只补最后一刀，让己方小兵逐渐累积，形成一波比对面大的兵线，然后一起推进塔。

## 收益

| 收益 | 说明 |
| --- | --- |
| 越塔有兵 | 兵多才能抗塔、才能越塔杀人 |
| 吃镀层 | 大波兵压塔，对面不敢出塔清 |
| 限制补刀 | 对面在塔下一波波漏刀 |
| 锁住对面 | 对面必须留在线上清兵，不能游走 |

## 典型场景

女警用多波兵同时压补刀 + 点塔。这是"缓推"最标准的用法：**兵线替你打塔，你替兵线压人。**

## 风险

- 囤线期间你自己也不能走，一走兵线就白囤
- 兵线越囤越大，打野来一趟就是双杀
- 缓推的价值随时间下降，中后期不如直接快推转线

## 快推 vs 缓推怎么选

| 目标 | 选择 |
| --- | --- |
| 要回城、要支援 | 快推 |
| 要越塔、要镀层、要压发育 | 缓推 |
| 不确定 | 快推（更少坏结果） |
