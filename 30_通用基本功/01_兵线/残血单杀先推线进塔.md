# 残血单杀：先推线进塔，再考虑活命

> 结论：单杀之后兵线没进塔，这个单杀就是负收益。宁可吃塔伤害，也要把兵送进去。

## 判断标准

杀完人，先问一句：**我能不能把这波兵推进塔再回城？**

- 能 → 单杀是优势
- 不能 → 单杀是劣势（你交掉了血量、蓝量、技能，还留给对面一条好线）

## 做法

1. 立刻处理残余小兵
2. 必要时用肉身勾仇恨 / 扛塔，保证兵线进塔
3. 关掉自动攻击，别乱打
4. 兵线进塔后再回城或撤退

## 为什么值得

兵线进塔后，对面复活回来时线是往你这边推的，你复活上线就能在安全位置吃线。反之，线被对面冻在中间，你复活上线就是被压着打。

## 连锁崩盘路径

```
残血单杀不推线
  → 对面控线
  → 打野来抓
  → 掉塔皮
  → 丢小龙
```

一次处理失误能连锁到整局。
