# 单杀前先算清线能力

> 结论：单杀之前先问一句——杀完我能不能清线回城？答不能，就别杀。

## 判断

| 条件 | 结论 |
| --- | --- |
| 杀完能推线进塔 + 安全回城 | 杀，这是优势 |
| 杀完线推不动 / 必须残血站线 | 不杀，风险大于收益 |
| 对面打野位置未知 | 不杀，杀完就是被抓的靶子 |

## 为什么

单杀会消耗大量资源：血量、蓝量、技能、召唤师技能。如果换不来兵线优势和回城窗口，你只是换了一个人头，代价是接下来两分钟被压。

## 标准流程

```
完成击杀 → 立刻清线 → 兵线进塔 → 回城 → 带装备返线保持领先
```
