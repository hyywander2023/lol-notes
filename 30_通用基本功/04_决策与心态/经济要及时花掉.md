# 经济要及时花掉

> 结论：没花掉的金币不产生任何战力。10 个人头不买东西，等于 0 个人头。

## 阈值

| 金币 | 动作 |
| --- | --- |
| 1000 左右 | 可以考虑回城 |
| 2000 | 必须回城转化战力 |

## 为什么打野最容易犯

打野一直在刷，金币一直涨，很少回城。结果 15 分钟身上 3000 金，装备落后对面两件。

## 领先时的纪律

| 局势 | 行为 |
| --- | --- |
| 领先 | 只做确定性高的操作，不冒险 |
| 均势 | 可以找机会 |
| 落后 | 必须找机会 |

**领先时冒险是最亏的——你已经赢了，只需要不输。**
