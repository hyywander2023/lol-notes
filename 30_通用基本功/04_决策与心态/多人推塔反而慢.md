# 多人推塔反而慢

> 结论：塔周围的人越多，塔越硬。前期五个人一起推一座塔，是效率最低的做法。

## 机制

防御塔会因附近英雄数量增多而获得临时护甲（前期尤其明显）。所以：

- 技术上五人推更快
- 实际收益上五人推更慢（其他路全空）

## 正确分工（前期）

| 位置 | 该做什么 |
| --- | --- |
| ADC | 单独吃塔皮经济 |
| 辅助 | 做视野、回城补给 |
| 打野 | 清野、回城 |
| 中单/上单 | 各自处理兵线 |

**分开做事，效率更高。**

## 例外

后期推进时这条不成立——后期需要集中火力速推，且塔的护甲机制影响变小。
