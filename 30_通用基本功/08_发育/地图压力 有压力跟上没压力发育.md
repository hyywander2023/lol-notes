# 地图压力：有压力跟上，没压力发育

> 结论：队友正在制造压力就同步行动；没人给压力就专心发育——别硬跟团。

## 双规则

| 队伍状态 | 你的动作 |
| --- | --- |
| 有地图压力（如一路推到高地） | 同步进攻 / 支援，别被抓 |
| 无地图压力 | 转稳妥打法，专注发育 |
| 附近有小团且必胜 | 就算亏兵也去 |

## 温水煮青蛙

把对手压残后别上头追杀。他待在线上迟早会死，而且一路亏刀——你专心补刀、吃镀层，等必胜团战在附近爆发，或者等他自己来找你。敌方打野来帮劣势线，是你惩罚他的机会，最好情况能双杀。

## 执行

- 外塔倒塌后对面支援变快，别过度深入。
- 敌人消失时默认推线 + 刷野；没附近野怪就回城花钱。
- 队友强行开团，吃装备的核心位坚持发育更值；怕刺客就靠前期发育，装备成型后威胁自然降低。
