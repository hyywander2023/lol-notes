# 前期不落后比完美补刀重要

> 结论：前期为补刀送一次血，比少补几个刀亏得多——补刀差距是后期运营拉开的。

## 前期 vs 后期

| 阶段 | 重点 |
| --- | --- |
| 前期 | 不落后 + 血量优先；死亡代价小，别为一个刀拼命 |
| 后期 | 推线、刷野、塔掉后多波兵同时进，效率翻倍，差距在这里拉开 |

超高的补刀领先来自后期运营，不是前期对线。前期就算完美补刀，也拉不开真正决定胜负的差距。

## 后果链

```
前期劣势 → 装备少 → 清线慢 → 推不动线 → 团灭后被一波
```

这条链起点往往就是「为了一个刀残血不回家」。

## 执行

- 中期开始死亡代价剧增（复活时间长，每一秒都珍贵）。
- 别为了一个刀进入敌方技能范围，见 [[高风险补刀要算账]]。
- 钱攒够了就回城转化战力，见 [[经济要及时花掉]]。
