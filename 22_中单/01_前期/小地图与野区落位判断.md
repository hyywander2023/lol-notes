# 小地图与野区落位判断

> 结论：敌方打野钻得太深（如三狼）就正常推线别去支援，对面中单消失就「你不去我也不去」靠推线施压。

## 野区落位决策
| 打野位置 | 中单做法 |
| --- | --- |
| 三狼等极端位置 | 猛推线，别过去；位置深、我方到得更快 |
| 过深 / 敌方蓝区 | 让打野自己应对，除非已把对位压塔下且推完线 |
| 位置较浅 | 可考虑支援，仍要确认有肉吃 |

## 镜像与自主判断
- 对面中单消失时，用「你不去我也不去」的对称策略，通过推线施压。
- 评估自身清线速度（瑞兹 3–4 秒是临界值）决定优先推线还是立即支援。
- 不盲目跟 ping：国服打架频繁，是否支援要自己判断收益，职业队才完全听指挥。

## 特殊风险
- 敌方打野把蓝 Buff 拉到非标准位置，警惕拉扯战术。
- 二级巴德可能学 E 位移拉扯，优先对线。
- 敌方打野亏损时，我方线上也可能同步亏损，支援前算清这笔账。
