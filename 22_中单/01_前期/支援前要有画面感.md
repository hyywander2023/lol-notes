# 支援前要有画面感

> 结论：支援前先判断去了有没有收益（能不能吃到肉/拿双 Buff/混助攻），预判成功率低于七成就老老实实推线并 pin 信号。

## 决策流程
| 步骤 | 动作 |
| --- | --- |
| 1 切屏 | 决策前至少 3 次小地图切屏：看打野位置、敌方技能 CD、兵线交汇点 |
| 2 判收益 | 有肉吃就去；没肉吃就推线，宁可亏点线也不盲去 |
| 3 判风险 | 成功率低于 70–80% 选择稳健推线，连 pin 两次危险信号 |
| 4 止损 | 敌方核心控制（如牛头 Q）进 CD，胜率评估上调 20–30%；关键技能 miss 后 0.5 秒内撤退 |

## 兵线要先算
- 同时看当前兵线位置和未来 3 波走向，尤其是炮车线。
- 常见失误：支援时忽略回推线，逛两三秒回来发现线被卡在不利位置。
- 已有兵线处理原则：塔前有兵不支援。

## 心态
- 实战一次只做一个决策（去/不去），复盘时再判最优解，不左右互搏。
- 决定后队友强行开团失利，复盘坚持「决策隔离」，专注决策本身合理性。
