# 中期指挥与残局沟通

> 结论：指挥只围绕一个目标（如"去上路拿线权再点亮视野"），提前约 30 秒说清；残局让活着的人报信息、操作者自主决策。

## 沟通分工
| 阶段 | 主导 |
| --- | --- |
| 前期资源团 | 打野指挥 |
| 中期团战 | 双 C 参与决策 |
| 运营阶段 | 听野辅指挥 |
| 非主战场的人 | 不指挥全局 |

## 目标明确
- 五排可讲细节，路人局只给方向：围绕一个地方打架即可。
- 开团前定触发条件（如"对面进河道就开"），别临时起意。
- 队友不配合就转向下一步，不反复拉扯心态。
- 残局别用技能提示催队友，信息报清楚后交给操作者自主处理。
