# 中期节奏：先预判下一波资源点

> 结论：每波线处理完就切小地图定下一波资源（先锋/小龙/虫子），在刷新前回城更新装备并提前到位，别为镀层拖节奏。

> ⚠️ 版本差异：课程为旧数值，已按 2026 赛季更新。

## 节奏判断
| 时机 | 动作 |
| --- | --- |
| 清完当前线 | 切地图确认下一波资源落点与刷新时间 |
| 资源刷新前 | 回城更新装备、带真眼，算好到位时间 |
| 资源已失 | 转边线推塔或控另一半区，别空线跟着跑 |
| 线上有优势 | 推完线先动，用时间差先到战场 |

## 两个常见失误
- 贪镀层：镀层已永久，为它推迟回城，等于带着旧装备进资源团。
- 空线参团：线没处理就消失，回来亏两波兵线，节奏断在自己手上。

## 辅助判断
- 打野的节奏要独立：别因为队友失误打乱自己发育。
- 小龙已失时，下一波常围绕虫子/先锋展开，提前把线推过去。
