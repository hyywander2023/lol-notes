# 中线权压制野区

> 结论：持续推线让敌方打野不敢下河道；推完线在盲区静止约 3 秒再回线，用"消失"逼对面回城，不必真跑过去。

## 线权到野区的转化
| 己方状态 | 可做的事 |
| --- | --- |
| 中线持续有线权 | 限制敌方打野活动，他不敢进河道 |
| 打野进某半区 | 中单跟着持续推线施压，别空线 |
| 推完线且耗到血量 | 进敌方野区做视野，干扰打野发育 |
| 对方向另一半区转移 | 趁机控线吃线，不盲目跟 |

## 消失施压
- 在敌方视野盲区静止约 3 秒即可传递"中单 miss"信号，不用走到河道尽头。
- 给压后立刻回线补刀：对面误判你游走会取消回城或缩塔，白亏一两波兵。
- 推完线别消失过久，否则下路、上路和己方野区同时承压。
