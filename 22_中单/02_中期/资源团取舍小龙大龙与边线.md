# 资源团取舍：小龙、大龙与边线

> 结论：敌方运营小龙就换推上塔甚至二塔；拿到大龙后目标是推塔不是打架，中单通常待边线，带线遇人别死。

## 取舍表
| 局面 | 选择 |
| --- | --- |
| 敌争小龙 | 直接推上塔/二塔，用塔换龙的经济 |
| 已拿大龙 | 全员明确推塔目标，中单在边线活动 |
| 带线遇人 | 保证不死，拖住给大龙 buff 创造价值 |
| ADC 没闪没位移 | 中单才留中挂机，ADC 去推边线 |

## 风险提醒
- 过河道吃边线必须有视野，野辅不来就自己插眼，宁可放弃这几刀。
- 中期别抢 ADC 的中线（15 分钟后默认归 AD），各吃各的才不内耗。
- 无谓的 5v5 聚集是团队意识不足：目标不明确时宁可推塔。
