# 先锋与虫子的接战判断

> 结论：接资源团前先数人数（含敌方辅助）并查关键大招，缺前排、缺开团就别接；劣势时用下路一塔换先锋，净亏可接受。

## 接战前自查
| 检查项 | 不通过就放弃 |
| --- | --- |
| 人数 | 敌方辅助刚露头别硬上，警惕 3v4/4v4 |
| 大招 | 己方关键大招未好、对方有开团，别接 |
| 阵容 | 无坦克吃技能、无稳定开团，进场即死 |
| 兵线 | 中线没处理就别去，先推完线再动 |

## 劣势处理
- 被动阵容上单补奥恩/塞恩/石头人，提供开团与承伤。
- 三路被压时选择性放弃资源换击杀机会，等对方资源团反打。
- 放弃先锋换下路一塔：一塔换一塔，实际只净丢中塔，可接受。
