# 中塔与转线节奏

> 结论：中一塔是地图最重要的塔，靠先锋推而不是平 A 磨；掉塔后立刻转上或转下，必要时放弃中塔换边线资源。

## 推进与转线
| 情况 | 处理 |
| --- | --- |
| 有先锋 | 用它撞中塔，别用平 A 慢慢磨 |
| 上路推不动 | 中上换线，让优势路去吃塔 |
| 己方中塔将掉 | 守二塔即可，换边线一塔做交换 |
| 一波推进完成 | 及时接管中线转向，别拖到炮车线失控 |

## 节奏延伸
- 敌方拿先锋后常规打上：把上路线推出、视野做好再进攻，可拖它的整体节奏。
- 下塔已破时，清完线提前向下路靠，别等对方动先锋才反应。
- 中塔掉落后视野范围变大，趁势入侵野区做眼。
