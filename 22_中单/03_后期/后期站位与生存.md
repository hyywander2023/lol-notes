# 后期站位与生存

> 结论：别站太前，保持安全输出距离；血量过低立刻撤退，别在圈里吃减速被人一套带走。

## 站位要点
| 风险 | 处理 |
| --- | --- |
| 第一时间站得过前 | 先往后拉，等对方关键技能交出再进 |
| 飞天/进场位置差 | 宁可少打伤害，也别被秒 |
| 血量低 | 及时撤，别贪输出被"一脚踹死" |
| 在阿塔汗圈内 | 站到圈外，避免被动减速 |

## 心态
- 第二时间到场完全可以接受，不必强抢先手。
- 蹲人没把握就别蹲，尤其对灵活 C 位（如卡莎）。
- 复活或回线后先确认状态再行动，别带残血进资源团。
- 团战前先确认自己站在哪个象限，别跟着人群盲目往前挤。
