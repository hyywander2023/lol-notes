# 等级与团战雪球

> 结论：中后期一波线的经验足以卡关键等级，落后就先补级别盲目参团；复盘要看"对线失误→等级落后→团战溃败→资源丢失"这条链。

## 等级价值
| 现象 | 处理 |
| --- | --- |
| 不当支援导致落后 2–3 级 | 优先补等级，有 TP 兼顾发育与支援 |
| 一波线没吃 | 等于亏两波，等级节点被卡 |
| 等级不足参团 | 靠团队配合完成升级，别硬打 |
| 共享经验（如阿塔汗） | 留意等级差，别让对方白吃等级 |

## 复盘视角
- 雪球始于对线期失误，别只看最后的团战溃败。
- 前期关键团处理不当会直接影响后期局势。
- 职业选手先补状态、再支援、速度适中——不快也不慢。
