# 变奏：打破节奏的突然行动

> 结论：变奏是放弃常规吃线去做埋伏，前提是提前沟通；打大龙前先定"打人还是 rush"，避免出现三人打龙、两人打人。

## 执行要点
| 要素 | 要求 |
| --- | --- |
| 时机 | 关键节点突然改变节奏（如放弃下路大波兵去野区埋伏） |
| 沟通 | 提前告知队友补位，否则漏位会被全员针对 |
| 目标 | 打大龙时统一：先打人还是先 rush 龙 |
| 站位 | 前排卡隘口，后排保安全距离 |

## 风险
- 变奏需要队伍默契与精准时机，路人局慎用。
- 沟通不足时，队友按常规节奏行动，反而漏位送兵线。
- 打成一盘散沙时先停手统一目标，别各打各的。
