# 后期大招与关键技能时机

> 结论：大招留给收割或关键控制，别锁定有位移的 C 位；等对方关键技能交出再进场，被控瞬间立刻开保命技能。

## 时机表
| 技能 | 正确用法 |
| --- | --- |
| 大招 | 留作收割或控制关键前排，有刷新机制可二次使用 |
| 位移进场 | 等对方 C 位大招交出后再突进 |
| 保命技能（如 W） | 捏住应对硬控，被睡/被控瞬间秒开规避后续伤害 |
| 第二个大招 | 分段击杀时别漏放，先秒一个再转火 |

## 复盘要点
- 团战失误常不是"没打伤害"，而是大招交给了错的目标。
- 前期几波关键团处理不当会直接连锁到后期。
- 分段击杀（先秒前排再处理 C 位）优于同时攻击多个目标。
