# 后期资源交换与分带时机

> 结论：远古龙刷新前让人带下路牵制；用上路塔换远古龙要全队统一执行，放龙换发育也算一笔账。

## 交换表
| 局面 | 处理 |
| --- | --- |
| 远古龙将刷新 | 让剑魔类英雄带下路，其他人保持机动 |
| 敌方拿龙魂 | 放龙换发育时间，评估翻盘可能 |
| 上路塔 vs 远古龙 | 团队统一执行塔换龙的决策 |
| 优势兵线 | 把对手压在二塔，换取野区主动权 |

## 分带纪律
- 分带英雄（如剑魔）单带吸引多人回防，为队友创造多打少。
- 劣势时别盲目分带：会被卡萨丁+蔚这类组合单抓。
- 等级装备落后就牺牲发育帮队友，别一心想 C。
