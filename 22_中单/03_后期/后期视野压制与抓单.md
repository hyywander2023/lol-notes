# 后期视野压制与抓单

> 结论：用真假眼点亮对方野区封锁其活动空间，靠机动组合抓单形成局部多打少，为拿龙魂铺路。

## 视野与抓单
| 动作 | 目的 |
| --- | --- |
| 红 buff 野区插满真假眼 | 封锁敌方活动空间，压得出不了塔 |
| 机动组合（如阿狸+洛）野区抓单 | 视野优势转为局部多打少 |
| 兵线优势时去蹲 | 兵线决定谁去蹲，抓做视野的辅助/打野 |
| 大小龙刷新前 | 先布视野再动资源，别盲开 |

## 注意
- 排完眼若没收益，果断放弃并重新调整站位，别死磕。
- 河道无视野时不要贸然开团，先让人照亮再打。
- 做视野的人要有人保，独自深入会被蹲。
