# 团战目标选择：先打被控与前排

> 结论：控制挂在谁身上就集火谁，先处理被控的前排、逼出金身或闪现再转火 C 位，别执着切有位移的后排。

## 目标顺序
| 局面 | 做法 |
| --- | --- |
| 己方控制挂到前排 | 全队转火该目标，按刷新机制再转后排 |
| 对方 C 位有大招/位移 | 等他交出位移再进场，别提前飞 |
| 多人集火已锁定 | 跟随队伍集火，不单独切另一个 |
| 大招可用 | 留作减速或收割，别固定给 AD |

## 反面案例
- 连续把大招强杀有位移的卡莎导致团战失利；正确是先减速前排，击杀后再转 AD。
- 职业选手（鳄鱼）放弃单切 GALA、配合队友秒前排——伤害统一比个人切入更有效。
