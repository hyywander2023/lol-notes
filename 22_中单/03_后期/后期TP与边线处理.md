# 后期 TP 与边线处理

> 结论：有 TP 就别徒步上线（白丢 1–2 波经验）；状态差先回家补装再 TP 回线，有 TP 去带危险线、没 TP 就抱团。

## TP 用法
| 情况 | 做法 |
| --- | --- |
| 团战后要回线 | 直接 TP，别步行，省下 1–2 波兵线经验 |
| 状态差且身上有钱 | 先回家补装（如出盾），再 TP 出来 |
| 有 TP | 可带危险线牵制，或吃线后 TP 正面 |
| 没 TP | 跟团，不单独去边线 |

## 带线价值
- 主动凶悍带线吸引敌方注意，为队友创造 4v4 甚至偷龙机会。
- 守二塔吃线后 TP 正面，比过早参团损失资源更划算。
- 别被队友情绪带偏：AD 催你去中路时，先算清兵线价值再决定。
