# 优势扩散循环

> 结论：打出优势后按「推线进塔→进敌方野区→摇队友拿先锋/抓中→推中塔→回上路接线」循环，前提是做好视野不被抓。

## 扩散流程
| 步骤 | 动作 |
| --- | --- |
| 1 推线进塔 | 把兵推到对方上路二塔处 |
| 2 侵野 | 确认无人抓你后进对方上半野区吃野 |
| 3 辐射队友 | 上半区成为你的控制范围，摇队友打先锋或潮虫 |
| 4 游走抓中 | 去中路蹲守，击杀对方中单/打野 |
| 5 推中塔 | 集合队友推掉中路一塔 |
| 6 循环 | 回上路继续接线，重复以上步骤 |

## 关键前提：不被抓
- 在河道、野区入口布置视野，确保自身安全。
- 只要不被抓，节奏就能滚动起来；优势后不知干什么时，看地图找资源：中路塔暴露就往中路靠，中路无战事就转上路接线。

## 资源团处理
- 把兵线推到对方塔下，迫使对方选择：能杀上单就杀、顺势拆二塔；不能杀且对方来抓，就转线抓其他路落单英雄。
- 核心是让队友和你进入同一条轨道，形成以多打少拿资源团。
