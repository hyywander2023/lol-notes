# 坦克出装营养均衡

> 结论：坦克出装要护甲、魔抗、生命值三者兼顾，对面双 AP 时那 800 金别买护甲，改买 850 的魔抗。

## 通用原则
| 对面 | 出装 |
| --- | --- |
| AP 多 | 优先水银鞋（魔抗+韧性） |
| AD 多 | 出小反甲（护甲+重伤），散件挂着即可 |
| 双 AP | 小反甲后补 850 魔抗（如败魔），别再花 800 买护甲 |
| 血量偏低 | 补红水晶，后续可合狂徒或石像鬼石板甲 |

- 有效生命 = 生命 × 抗性，必须一起堆，避免被单一属性穿透克制。
- 缺魔抗会被 AP 打得很痛；对面阵容均衡，你的出装就必须均衡。

## 对格温（AP 爆发）出装
- 重伤只做小重伤（800 金）挂着，不合成大重伤刀（性价比极低）。
- 必出 850 金魔抗斗篷（负极斗篷）：不出同等装备会被格温秒，出了能硬吃一套靠小鬼拉扯死。
- 核心：血手（护盾+容错）必出；青龙刀可选；星虫太后期且缺容错，不推荐。
- 顺序示例：小重伤 → 青龙刀 → 血手 → 850 魔抗 → 后续核心；或直接败魔硬抗。
