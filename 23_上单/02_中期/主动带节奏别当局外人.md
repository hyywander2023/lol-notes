# 主动带节奏别当局外人

> 结论：上单要自己判断能不能打、主动发信号指挥队友，别被队友牵着走成「局外人」。

## 节奏失控的表现
- 队友打架就 TP 支援，队友撤退就回家，既没吃到线也没拆到塔。
- 塔不是自己拆的、架不是自己打的，赢了无关、输了背锅。
- 五黑时容易习惯性听队友安排，更要自己判断这波能不能打。

## 正确做法
| 场景 | 动作 |
| --- | --- |
| 该推塔 | 主动指挥「TP 堵后，你们到后面跟」，果断开团，不犹豫 |
| 队友在别处打架 | 先去吃上路线、把线带过一塔，即使团输了塔也能拆 |
| 没大招 / 没好 TP 位 | 不盲目支援，优先处理兵线 |
| 带完线队友还在打 | 推完塔再绕路跟团也来得及 |

## 指挥要点
- 提前规划每一步，明确告诉队友「什么时候打、该干嘛」。
- 果断开团：大招撞过去，即使被 Q 躲也能逼出闪现，再去拆塔。
- 堵后 TP 要果断，等队友打完再 TP 过去意义就不大了。
