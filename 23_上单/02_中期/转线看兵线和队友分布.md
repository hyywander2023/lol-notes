# 转线看兵线和队友分布

> 结论：出门去向不看「想做什么」，只看兵线情况和队友分布——别去有 C 位正在接线的那条路。

## 判断方法
| 依据 | 做法 |
| --- | --- |
| 队友分布 | 薇恩在下路接线、皎月在上路 → 你去中路接线 |
| 兵线情况 | 哪条路没人吃、兵线需要清，就去哪 |
| 吃线到底 | 安全前提下把兵带到对方塔下，让对方亏线 |

## 转线流程
1. 先吃中路兵线 → 再转下路或配合队友行动。
2. 三条路分配：AD 一路、中单一路、上单一路，各取所需，不与 C 位抢线。
3. 满状态不必频繁回家，影响发育节奏。

## 避免无效逛街
- 队友未开战、没有好 TP 位时，继续带线，别在地图上乱逛浪费发育时间。
- 常见细节失误：绕圈浪费时间，漏吃 2–3 个小兵。
- 抓人成功后别盲跟队友（他们去刷野/做视野没意义），继续把线带进对方塔下施压。
