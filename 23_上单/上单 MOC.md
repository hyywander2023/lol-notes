# 上单 MOC

> 前期主线（出兵到一塔）：保发育、赢对线，靠兵线与强势期把优势锁死 → 中期主线（一塔掉即进入）：分清单带型还是坦克型 → 单带型推线单杀拆塔、坦克型围绕资源团 → 后期主线：先定英雄定位，找「杀谁能赢」的锚点，只打能赢的团、保自己不死。
>
> 通用底层（兵线/防御塔/资源交换）不在本目录重复，见「关联」。

## 四、速记（打完一局自查）

1. 我这一局是单带型还是坦克型？打法用对了吗？
2. 单带时，我死过几次？每次死是不是都在没视野的地方？
3. 坦克团战前，我把兵线推进对方塔下了吗（兵马未动粮草先行）？
4. 对格温这种 AP，我出 850 魔抗了吗？那 800 金是不是又买了护甲？
5. 这局是我带节奏，还是被队友牵着走？
