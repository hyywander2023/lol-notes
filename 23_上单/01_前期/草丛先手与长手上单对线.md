# 草丛先手与长手上单对线

> 结论：打薇恩这类长手，核心是抢草丛贴脸——战士护甲 30+ 高于远程的 23 点，打到就不亏，压血线后抢二单杀。

## 对线流程
| 步骤 | 做法 |
| --- | --- |
| 抢草 | 占草丛藏视野，对方放眼就换一个草 |
| 贴脸 | 有位移直接贴，逼其无法拉开 |
| 换血 | 护甲差决定换血不亏，打到即赚 |
| 收尾 | 压血线 → 抢二 → 单杀 → 控线 |

## 关键
- 一级抢草丛获取先手位（青钢影对诺手同理），避免在敌方塔下作战。
- 远程英雄靠消耗，但被贴脸后优势全无；别被「手长」吓住。
- 长手英雄补刀抬手时是贴脸最佳时机，配合草丛视野差打一套再退。
- 天赋配合打法：想前期分胜负带骸骨镀层，能挡第二发平 A；只想抗压发育就带复苏之风。
