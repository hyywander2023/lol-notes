# 清线困难英雄的前期生存

> 结论：青钢影、剑姬这类清线慢的英雄，前期一死兵线就变回推、传送回线仍劣势——用身体扛线把兵带到塔前再推。

> ⚠️ 版本差异：课程为旧数值，已按 2026 赛季更新。

## 困境与解法
| 场景 | 处理 |
| --- | --- |
| 前期死亡 | 兵线变差（回推），别急着 TP 回线硬清 |
| 回推线兵多 | 3 远程兵≈1 个 ADC 输出，主动找架借小兵伤害 |
| 线推不进 | 扛住兵线拉到己方塔前，再推进塔 |
| 抗压 | 让防御塔吃掉一个小兵，兵线自然回推 |

## 概念区分
- 2026 分路任务完成后上单获免费/强化传送，守线与回线的节奏按新机制走，旧课程「省 TP」逻辑只保留原理。
- 清线慢不等于被动：把线控在塔前，对手再克制也发挥不出来。
