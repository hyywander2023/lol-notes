# 兵线进塔后的十秒

> 结论：确认这波兵都会被塔吃掉后，立刻离开塔下做眼或看打野——这十秒是免费的，站着发呆等于把优势送回去。

## 时间窗口
| 动作 | 收益 |
| --- | --- |
| 做眼 | 蓝方河道草、红方三角草/河道入口，覆盖河道与野区入口 |
| 收集信息 | 看打野在不在打野怪、野怪刷新、其他路动向 |
| 等回推 | 别主动 A 兵，让兵线慢慢推回己方塔前 |

## 代价
- 塔下发呆、主动 A 兵会破坏回推线，把自己送到危险位置。
- 兵线永远在对方塔前极易被抓；闪现交过后打野来必死。
- 上单孤立无援，信息就是命：不做眼 → 被抓 → 优势归零。
- 钻石局腕豪前期有优势却被反复抓，问题就出在兵线进塔后不去做眼、只会塔下发呆。
