# 对线刀妹：一级压制流程

> 结论：刀妹一级极弱，要 Q 四个兵叠被动才强——开局拉兵线让兵回推，她敢 A 兵就直接打，任何英雄一级都能赢。

## 固定流程
| 步骤 | 做法 |
| --- | --- |
| 拉兵 | 走到兵线前吸引仇恨，把兵拉向己方 |
| 控线 | 让对方小兵更多，兵线慢慢回推 |
| 压制 | 她敢上来补兵就打一套 |

## 为什么有效
- 拉兵后形成回推线，兵线卡在己方塔前，安全且易配合打野。
- 刀妹无防 Gank 能力，打野不来往往是你没做回推线，不是打野的锅。
- 大兵线进塔后推完立刻走到兵线前吸引仇恨，让三个远程兵集火一个，主动控平衡。
- 刀妹要 Q 四个兵才叠起被动，一级窗口不去压她，等她叠满就没机会了。
