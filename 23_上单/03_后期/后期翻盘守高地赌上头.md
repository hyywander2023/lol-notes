# 后期翻盘：放资源、守高地、赌上头

> 结论：经济差拉大就别争小龙大龙——放资源守高地，赌对面冲进来，集火秒关键人物拿赏金，拖到自己装备成型。

## 翻盘路径
| 步骤 | 做法 |
| --- | --- |
| 判断 | 经济差过大，放弃野区资源争夺 |
| 防守 | 守高地，躲在队友身后 |
| 抓机会 | 等对面关键人物上头冲进来，集火秒杀 |
| 目标 | 拖到装备成型，能一打多再正面接团 |

## 原则
- 大后期是五个人的游戏，别想单人 carry；但 carry 型英雄要保自己发育到能翻。
- 心态上不依赖队友，先把自己装备做起来。
- 对面不犯错就等，别主动开必输团送掉翻盘希望。

## 执行要点
| 环节 | 做法 |
| --- | --- |
| 装备判断 | 差一件核心就继续清线，别急团 |
| 高地防守 | 站在核心队友身后，等对方先手 |
| 抓失误 | 核心上头冲进来，集火秒杀拿赏金 |

- 拖时间就是收益：只要不崩，装备差距会随补刀逐渐缩小。
