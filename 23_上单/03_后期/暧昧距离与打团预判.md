# 暧昧距离与打团预判

> 结论：后期站「我能打到你、你打不死我也开不到我」的暧昧距离——他开你就躲一个技能骗掉，进可攻退可守。

## 暧昧距离
| 要素 | 要求 |
| --- | --- |
| 能打到 | 你有机会输出对方 |
| 打不死/开不到 | 你留着退路和保命技能 |

- 对面开你，往后躲他一个技能，骗完再反打。
- 对方核心很肥时，先拉扯他一套逼出技能，再回头保队友一起杀，别单独上。

## 打团前预判
- 先想清楚：对方有没有闪现、辅助有没有控制（如钩子、击飞）、杀他要不要交闪躲技能。
- 想清楚再打，团战就简单；不肉身开团，让队友先手逼技能，你等收割机会。
- 保证发育的前提下，不打必输团，只打一定能赢的团。
