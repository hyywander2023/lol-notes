# 只打能赢的团：找锚点

> 结论：先找到「杀谁能赢」的锚点（如对面核心打野），围绕他做动作；小龙团打不过就换先锋压二塔——只打能赢的团。

## 找锚点
| 步骤 | 动作 |
| --- | --- |
| 定关键人 | 找出对面节奏核心，杀他一次就能断节奏 |
| 定资源 | 打不过的团直接放，换能拿的资源 |
| 定 TP | 分路任务完成后有免费/强化传送，支援前先想清楚值不值 |

## 原则
- 没必要打的团不打；核心输出已死、辅助残血时的 2 打 4/5 毫无意义。
- 对面集结资源时去压二塔，是交换而非避战。
- 打团前做心理预测：对方闪现、辅助控制、自己要不要 TP 躲技能，想清楚再打。
