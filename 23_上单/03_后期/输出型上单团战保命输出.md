# 输出型上单团战：先保命再输出

> 结论：船长、阿卡丽这类输出上单团战当 ADC 玩——开团前先看对面保命装（如盾弓），摆桶/消耗压正面，绝不追残血 1v1。

## 团战流程
| 步骤 | 做法 |
| --- | --- |
| 收集信息 | 确认对面关键保命装是否触发，别把肉当脆皮 |
| 占视野 | 真眼卡路口，占据安全输出位 |
| 压正面 | 摆桶或技能消耗，逼对方核心着急进场 |
| 保命收割 | 队友被秒也先保自己，等对方技能交完再收割 |

## 致命失误
- 残血目标追击时忽略其保命装，闪现技能 all in，被反杀直接团崩。
- 队友可以卖，前提是你活着能收光对面；活下来才有输出。
- 保命技能（水银、金身、烟幕）没好时，绝不走到对方核心输出脸上。

## 收割思路
| 阶段 | 动作 |
| --- | --- |
| 开团前 | 远程消耗压血，不冒进 |
| 技能交换后 | 对方关键控制交掉再进场 |
| 残局 | 逐个点掉残血，不 1v1 追核心 |
