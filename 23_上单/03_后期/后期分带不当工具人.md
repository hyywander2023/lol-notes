# 后期分带：别当工具人

> 结论：阿卡丽、船长这类发育/收割型上单别当工具人跟团——中路推不上去就转上路压线，制造两路兵线压力。

## 该不该跟团
| 场景 | 做法 |
| --- | --- |
| 队友中路推不动 | 转上路压线，制造两路压力 |
| 队友残血求 TP | 不急支援，先推线拆水晶 |
| 对面去打大龙 | 先拆水晶再 TP，形成兵线压力+收割 |

## 要点
- 单挑无敌就安全带线；两分钟无效跟团 = 白送发育。
- 输出型英雄没有留人/抓人能力，充当开团工具人是错位。
- TP 别浪费在没必要的小团；存下来用于兵线压力和关键收割。
- 制造两路压力后，对方回防顾此失彼，你方其他路更好推进。
