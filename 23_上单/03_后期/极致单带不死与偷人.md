# 极致单带：不死、偷人、配合队友

> 结论：乌迪尔这类无打团空间的英雄，赢法是「发育不死 → 蹲草偷人 → 配合队友」，把 1v2 拆成两个 1v1。

## 核心三件事
| 事项 | 做法 |
| --- | --- |
| 不死 | 死一次节奏全崩；打残两人就撤，别追杀 |
| 偷人 | 蹲草等对方脸探，晕住直接开高攻速技能秒人 |
| 配合 | 叫队友蹲、抓守线的人、抓打野，别单打独斗 |

## 节奏细节
- 带线过河道被抓，别直接跑，蹲草偷人把被动变主动。
- 推线到二塔→中单来守就刷野→绕后配合队友秒 C 位。
- 带线必须把兵推到塔下让防御塔吃兵；已知对面位置就先吃完线再行动。
- 连招顺序：一技能晕住后直接开觉醒（高攻速），别先平 A 两下再开。
