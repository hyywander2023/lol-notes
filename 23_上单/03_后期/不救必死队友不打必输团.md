# 不救必死队友，不打必输团

> 结论：队友必死（无闪、残血、被包夹）就果断卖，别上前 1 打多——你是上单不是队友的狗，保住自己等收割。

## 必输局判断
| 信号 | 判断 |
| --- | --- |
| 核心输出已死 | 团战必输，别进 |
| 辅助残血、2 打 4/5 | 救援无意义 |
| 队友一技能已交 | 他必死，上去是一起送 |

## 替代方案
- 把兵线推过去、拆中路水晶；对面拿大龙也不是你的失误。
- 复盘每次死亡，共同点往往就是「救必死队友」或「打没必要的团」。
- 优先级：保证发育 → 等技能齐全 → 团战收割时再重拳出击。
- 无视野时走野区（最多一两人埋伏），别走兵线（可能多人包夹）。

## 心态
- 操作在线但思路混乱，是优势局翻车的根源；先把「不送」刻进本能。
- 队友送的不是你送的，下一波再找机会，别用一次冲动葬送整局。
- 该发育时发育，该支援时支援，把时间花在能产生价值的地方。
