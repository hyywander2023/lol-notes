# 野区营地与刷新

> 结论：记不住野怪时间，就没法推断对面打野在哪。

## 营地构成（每个半区对称）

| 营地 | 效果 |
| --- | --- |
| 蓝 Buff | 法力/能量回复 + 技能急速，约 2 分钟 |
| 红 Buff | 普攻附带灼烧减速 + 脱战回血，约 2 分钟 |
| 魔沼蛙 / 三狼 / 锋喙鸟 / 石甲虫 | 只给金币和经验 |
| 迅捷蟹 | 河道视野 + 加速区，不反击 |

空间分布：蓝色方蓝 Buff 在上半区、红 Buff 在下半区；红色方相反。

## 刷新（2026）

| 时间 | 内容 |
| --- | --- |
| 0:55 | 红蓝 Buff、三狼、锋喙鸟 |
| 1:07 | 石甲虫、魔沼蛙 |
| 2:55 | 迅捷蟹 |

重生：红蓝 Buff 约 5 分钟，普通营地约 2 分多，迅捷蟹约 2 分半。

## 用野怪时间推断打野位置

| 观察 | 推断 |
| --- | --- |
| 开局哪条线帮打野（上线晚） | 他多半从那一侧开 |
| 刷完一侧需要的时间 | 约 3 分钟全清一轮 |
| 3 分钟左右 | 大概率出现在另一侧河道 |

**打野的位置信息是全图最重要的信息。** 每个线上玩家都该根据「对面打野在哪」决定能不能压线。

## 野怪机制

- 被拉离营地太远或太久会「脱战」回位并快速回血
- 惩戒只有打野带，有充能（最多 2 层），抢龙本质是拼最后一击
- 携带红蓝 Buff 的英雄被击杀，Buff 转移给击杀者
