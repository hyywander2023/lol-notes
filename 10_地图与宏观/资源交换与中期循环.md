# 资源交换与中期循环

> 结论：中期的核心循环只有一句话——推线拿线权，线权换视野，视野换资源，资源换塔。

## 循环

```
推线 → 获得线权 → 抢占视野 → 以人数/位置优势争资源 → 用资源优势推塔 → 回到推线
```

## 转线的默认答案

外塔倒下后对线结束，进入转线期：

| 位置 | 去哪 |
| --- | --- |
| 下路双人组 | 转中路（中路塔最重要、路最短最安全） |
| 中单 | 去边路带线 |
| 上单 | 去另一条边路带线 |

**这条分工不是规定，是默认解。** 特殊情况（比如中路已经被推掉）要重新分配。

## 资源交换原则

对面全员去打一个目标、己方赶不到时：

**不要硬接。去地图另一侧拿等价资源。**

| 对面在拿 | 你该拿 |
| --- | --- |
| 小龙 | 上半区巢虫/先锋、上塔、对面上半野区 |
| 男爵 | 对面下半野区、下路塔、第二条小龙 |
| 先锋 | 小龙、边路塔 |

## 边线必须有人处理

不处理的后果：大波兵线自己进塔，白丢金币甚至被推塔。

**打龙之前先把边线推出去**，这是标准流程。2026 赛季 14 分钟后出兵更快，被忽视的边线累积得更快。
