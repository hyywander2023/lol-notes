# 防御塔与镀层

> 结论：2026 赛季镀层永久存在——任何时间点磨塔都有金币回报。单带的价值比以往高。

## 推塔顺序（不可跳）

```
外塔 → 内塔 → 水晶塔 → 召唤水晶 → 两座门牙塔 → 水晶枢纽
```

前一个没倒，后一个无敌。至少摧毁一个召唤水晶后，门牙塔才可被攻击。

## 塔的攻击规则

| 规则 | 说明 |
| --- | --- |
| 优先目标 | 炮车/超级兵 → 近战兵 → 远程兵 → 英雄 |
| 转火英雄 | 你在塔射程内打敌方英雄，塔立刻打你 |
| 伤害递增 | 对同一英雄连续攻击，每发约 +40% |
| 必中 | 塔的攻击无法躲避 |
| 真实视野 | 塔能显形隐身单位 |

**「塔下不能随便打人」的全部原因就是转火规则。**

## 镀层（2026 变化）

- 外塔、内塔、水晶塔都有 5 层镀层，**永久存在**（旧版只有外塔、14 分钟消失）
- 外塔镀层金币从 11 分钟起逐分钟减少
- 外塔抗性也从 11 分钟起下降，对线期后更容易推
- 外塔生命值大幅提高

## 后门保护

塔附近没有敌方小兵时，塔获得大幅减伤。**推塔必须带兵线**，不带兵偷塔效率极低。

## 越塔三要素

1. 有兵线在塔下（小兵抗塔）
2. 有人抗塔（坦克或小兵）
3. 能在塔伤害叠高前完成击杀并撤出
