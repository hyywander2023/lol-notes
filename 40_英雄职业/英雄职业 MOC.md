## 职业克制环

```
刺客 ──克──> 脆皮法师、射手
  ↑                  │
  │                  │
  └── 克 ── 坦克/重装战士 ←── 持续输出克坦克
```

- 刺客克脆皮：能近身秒杀
- 坦克 / 重装战士克刺客：秒不掉，反被控
- 持续输出（射手、持续型法师、带百分比伤害的战士）克坦克
- 长手克短手（对线期），但短手有位移和控制时，在 Gank 配合下反克长手

> 经验规律，不是绝对。真正判断要看技能组和强势期，见 [[阵容三流派克制环]]。

## 对抗速查

| 对面是 | 你的解法 |
| --- | --- |
| 强开型坦克 | 站小兵后挡钩、拉散阵型，用反打流接它 |
| 保护型坦克 | 先骗保护技能，或走边线打拉扯 |
| 重装战士 | 长手消耗 + 重伤 + 躲关键判定 |
| 突进战士 | 留硬控等它进场，抱团不给落地机会 |
| 刺客 | 金身 / 复活甲 / 控制守卫，抱团 |
| 爆发法师 | 躲关键控制，它交完技能就是真空期 |
| 控制法师 | 水银解压制，走侧翼绕开正面 |
| 炮台法师 | 贴脸，别在中距离对射 |
| 射手 | 突进 + 硬控 |
| 保护型辅助 | 先杀它或先骗大招 |
| 特殊型 | 按强势期避开 |

## 使用守则

1. 先确认职业共性，再看个体机制。
2. 连招只是常见顺序，实际取决于距离、冷却、对方位移与控制。
3. 对位比较这六项：射程、位移、控制、回复、爆发与持续、强势等级段。
4. 涉及具体伤害、冷却、射程数值，一律查当前版本，本文不写数值。
5. 英雄重做会改机制，发现与当前版本冲突时以版本为准。
