# 快节奏环境的后期团战

> 结论：现代对局多在二十到二十五分钟结束，AOE 兼具伤害与控制——加速装备成型比追求完美后期更重要，劣势 3v5 时拼一波优于慢性死亡。

## 环境特征

| 变化 | 对 ADC 的影响 |
| --- | --- |
| 对局趋短（约 20–25 分钟） | 后期高度依赖前期铺垫 |
| AOE 兼具高伤害与控制 | 输出窗口缩短，刀尖舔血风险高 |
| 成型快的英雄压制成型慢的 | 六件成型可压三件 |

## 优劣势处理

| 局面 | 打法 |
| --- | --- |
| 优势 | 保持安全距离，稳定输出前排即可 |
| 劣势 | 必须冒险找输出机会；3v5 时拼一波优于慢性死亡 |

## 关键决策

- 核心不是完美团战操作，而是成型节奏——早一件装备比多等一个完美时机值钱。
- 躲技能导致队友减员时别陷入两难：撤退等于慢性失败，拼一波才有机会。
