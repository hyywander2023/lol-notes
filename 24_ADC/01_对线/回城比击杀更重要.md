# 回城比击杀更重要

> 结论：打赢换血或击杀后先处理兵线再回城把钱变成装备，别贪塔皮把优势赖在线上。

## 回城前查三件事

| 查什么 | 判断 |
| --- | --- |
| 兵线 | 能不能推进塔？推进去回城舒服，推不进可能亏兵甚至被卡线 |
| 金钱 | 够不够买核心小件/成装/鞋子？够就更值得回 |
| 状态 | 没血没蓝时，就算有线权也不一定能继续占 |

## 时机对比

| 理想时机 | 烂时机 |
| --- | --- |
| 大波线进塔，对面必须处理 | 兵线卡在中间，对面能把线冻住 |
| 资源见底、状态见底 | 只差一点钱却硬回 |
| 刚好够关键装备 | 有大波线要吃却被队友叫走 |
| 继续待在线上只增加风险 | — |

## 看装备，不看人头

判断当前能不能打，看双方已买出的成装、核心小件、鞋子、药水、召唤师技能和等级——对面 2-0 但钱没花，战力不一定高；你没头但买到强小件，反而更能打。对线是装备窗口游戏，不是比分游戏。
