# 射程压制与真空期换血

> 结论：有射程差就用普攻在安全距离白嫖，对面关键技能进冷却时立刻前压，别把优势期让过去。

## 换血三要素

| 要素 | 怎么用 |
| --- | --- |
| 射程差 | 手长一方站在多出来的射程外消耗，手短方补刀就上前压 |
| 技能真空期 | 对面关键技能交掉或冷却中，是安全换血窗口 |
| 兵线位置 | 在己方兵堆里打，吃小兵伤害的风险更低 |

## 开局动作

- 带扫描抢草丛视野，点掉对面的眼逼其后退。
- 与己方前排兵平行站位，慢推维持压制，别一上来推到塔下。
- 关键技能（消耗或开团技）留作换血威慑，别草率交掉。

## 别做的

| 错误 | 代价 |
| --- | --- |
| 优势期只 A 一两下就撤 | 符文和射程差都白给，对面安全过渡 |
| 推线过快进塔 | 丧失压制空间，对面舒适补刀 |
| 为补远程兵向前送血 | 血量见底后辅助开到人你也跟不上 |
