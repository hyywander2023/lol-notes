# 平行站位与止损

> 结论：和辅助站同一条战线再换血；辅助乱来时不教育、不硬救，把对线变成补刀游戏，别让他的失误变成你的死亡。

## 平行站位

| 站法 | 结果 |
| --- | --- |
| 你和辅助同步前压 | 两人能同时打到同一目标，对面一人被集火 |
| 你突前、辅助靠后 | 你被 2 打 1 |
| 辅助突前、你靠后 | 辅助被 2 打 1 |

观察四人位置：我能否打到对面？辅助能否跟上？对面有没有人落单？站位不平行就是机会，参差就是风险。

## 辅助不正常时

| 情况 | 你的处理 |
| --- | --- |
| 辅助明显送 | 不硬救，必输的架不为义气跟；最多补安全伤害，能换则换，不能换就卖 |
| 对线打烂 | 能快推就送线进塔，不能就慢推堆线后回城等线；把对线变补刀游戏 |
| 远程兵危险 | 该放就放，别为几个远程兵把血量交出去 |
| 下路一塔 | 守不住就放，死守送命是最不值的死法 |
