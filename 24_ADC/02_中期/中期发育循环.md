# 中期发育循环

> 结论：队友都挤中路时主动去边线、顺路吃野，形成「中线 → 边线 → 野怪 → 回城」的循环；去边路是补资源，不是当单带英雄。

## 发育循环

| 环节 | 要点 |
| --- | --- |
| 中线 | 先推完再决定去向 |
| 边线 | 哪条线兵最多、最安全、队友没去就去接 |
| 野怪 | 打野不在且野怪久未刷时顺路吃 |
| 回城 | 每次回程重看地图，按资源走不固定路线 |

## 边路安全五问

- 对面几个人在小地图出现？
- 谁能单杀我？
- 我有没有闪现和位移？
- 附近有没有己方队友？
- 推完这波线有没有安全撤退路线？

答案不清楚就只吃安全线，清完回头；不硬推二塔，不因多 A 两下塔交掉闪现和命。

## 刷野边界

不抢打野正在刷的野，不为野怪错过大波兵，不在无视野野区硬刷，不因一组野错过关键团。野怪是补充发育，不是核心目标。
