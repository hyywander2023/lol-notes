# 大乱斗 MOC

> 大乱斗（含海克斯大乱斗「海斗」）和召唤师峡谷的差别不在操作，在**出装权重**：对线运营被删掉，装备与海克斯直接决定这波团能不能打赢。
>
> 这一层的价值：进场前就知道第一件出什么，不用在加载界面才开始想。

## 四、边界（读之前先看）

- 这套是**大乱斗／海斗口径**，别搬去召唤师峡谷：峡谷要算线权、野区、镀层，大乱斗只算「这波团打不打得赢」。
- 数值与装备名随版本变（26.x）。旧视频、旧笔记里的装备名与现在不一致时，以当前版本为准。
- 源料是**作者经验总结 + 一次口播转写**，无对局数据支撑；与 [[出装推理框架]] 冲突时，保留原理、核对装备。转写里 3 个词无法确定具体装备，见速查卡末尾「术语核对」。
