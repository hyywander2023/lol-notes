# 辅助位公式出装

> 结论：辅助在大乱斗不是「少一个人」，是**给全队加属性的装备架**。核心只有两件：黎明核心（等于辅助的大帽）＋流水法杖（CD 人人都要）。

## 核心两件

| 装备 | 作用 | 口径 |
| --- | --- | --- |
| 黎明核心 | 治疗/护盾强度＋法强，等于辅助的「死亡之帽」 | 奶盾量的乘区，越早越赚 |
| 流水法杖 | 给队友 CD | **所有英雄都缺 CD**，给 4 个队友挂上，2000 块的装备能发挥五六千的价值 |

## 补第三件：解决触发真空期

- 流水、炽热香炉（原文「香炉」）都要**先提供护盾/治疗**才触发，一旦没盾没奶就是真空期。
- 所以补**歌之权冠**：会自动给附近队友治疗，能一直把流水/香炉的效果续上。
- 歌之权冠是女神之泪系可进化装备（由耳语头环成长而来），软辅缺蓝时顺路就把蓝解决了。

## 出装顺序

```
黎明核心 → 流水法杖 → 歌之权冠 → 香炉/针对性防御装
```

## 判据

| 情况 | 调整 |
| --- | --- |
| 队里两个以上吃 CD 的 C 位 | 流水优先级拉到第一件之后 |
| 我方没有护盾技能 | 歌之权冠提前，否则流水一直空转 |
| 对面爆发能秒 C 位 | 香炉换防御向装备，先让 C 位活过 8 秒 |
