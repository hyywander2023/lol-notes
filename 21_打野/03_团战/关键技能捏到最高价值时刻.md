# 关键技能捏到最高价值时刻

> 结论：闪现和大招不是用来补人头的；交出去之前先算值不值，杀低价值目标一律不交。

## 不交的账

- 用闪现去杀 0/3 的辅助，价值远低于闪现本身。
- 依赖闪现开团的英雄（伊莉丝 / 岩雀 / 莉莉娅），没闪时团战难度指数级上升。
- 上波乱交 → 这波没闪 → 被连锁击杀，这是最常见的崩盘链条。

## 该什么时候用

| 场景 | 判断 |
| --- | --- |
| 开团前 | 先确认敌方核心位置与关键技能 CD |
| 目标无闪且能配合队友必杀 | 才值得交 |
| 保命 | 关键位移留给活命，不留给追残血 |

## 协同注意

- 进河道等公共区域开扫描；被包夹风险来自多人消失视野。
- 面对多控阵容出水银饰带 / 水银鞋，少被控一秒就多一分操作空间。
- 打完一波就撤，别贪残血追击。
