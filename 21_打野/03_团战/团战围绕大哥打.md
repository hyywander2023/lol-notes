# 团战围绕大哥打

> 结论：团战只围绕双方核心的强度对比打——对面大哥猛就集火他，己方大哥猛就保他输出，自己是大哥就怎么舒服怎么来。

## 三步

| 步骤 | 动作 |
| --- | --- |
| 识别 | 找出双方阵容里的核心输出位 |
| 对比 | 判断对面大哥猛，还是己方大哥猛 |
| 选择 | 对面猛 → 想办法搞死他；己方猛 → 跟着他打 |

## 三种情形

- 对面核心更强：集中火力优先击杀。
- 己方核心更强：全力保护其输出，不用刻意切人。
- 自己就是核心：以自身输出环境为最高优先级，活着持续输出即可，不必刻意切后排。

## 保护核心的收益

明确这局跟谁有关、跟谁无关。核心位别走靠前的位置顶火力；核心被针对时，队友要及时支援。核心一死，翻盘希望就没了。
