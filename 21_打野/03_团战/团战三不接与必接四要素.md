# 团战三不接与必接四要素

> 结论：位置远、关键人缺席、视野差，占一条就别接团，转线换塔；三条反过来才果断开。

## 三不接

| 劣势点 | 表现 |
| --- | --- |
| 位置劣势 | 人离得远，还没开打就慢一步 |
| 英雄缺席 | 关键人没 TP、不在场，战力不足 |
| 视野缺失 | 一片黑，盲区会带来致命包夹 |

## 必接条件

最肥的两个敌人已死 + 四人集结 + 视野在手 → 果断开团，别错失战机。

## 不接的补偿

点信号，转线推塔：两到三波兵线配合换一座塔，运气好两座，零风险。对面来守，配合高爆发队友直接越塔。

## 止损

一换二只赚一个人头、没拿到战略资源仍是亏。打不过就别用关键技能换低价值击杀。
