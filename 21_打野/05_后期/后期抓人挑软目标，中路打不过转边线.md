# 后期抓人挑软目标，中路打不过转边线

> 结论：后期抓人要挑好抓的脆目标撕开防线，别死磕肉盾；中路团打不过就转边线抓单。

## 目标选择

| 情形 | 选择 |
| --- | --- |
| 软目标（缺位移 / 好控） | 优先抓，撕开突破口拿资源 |
| 肉盾 / 难抓目标 | 别死磕，效率极低 |
| 队友有定点控 | 配合他做事，效率质变 |
| 没有定点控 | 单人只能挂后，别硬先手 |

## 配合节奏

队友回城时不空蹲，先刷 Buff 等他就位；他复活后宁可少吃半区野怪也要跟他行动。做完事顺手点亮半区视野，别让信息断档。

## 中路不利时

中路 4v4 打不过就转边线抓单，避免正面冲突。抓单前先扫眼、从河道包夹，形成多打少。
