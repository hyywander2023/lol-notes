# 后期定位：向上兼容还是向下兼容

> 结论：后期能做什么，前期就定了——装备领先就主动找机会，装备落后就跟着队友蹭节奏，别硬装核心。

## 两种兼容

| 状态 | 后期做法 |
| --- | --- |
| 装备领先 | 向上兼容：主动标信号、找击杀、带动节奏 |
| 发育不良 | 向下兼容：跟随队友，别单人做事拖累全队 |

## 别让规划落空

| 错误 | 后果 |
| --- | --- |
| 前期无规划刷野 | 被对手牵着走，防御塔被拔 |
| 盲目跟野怪刷新 | 失去主动权，只能被动响应 |
| 优势不辐射 | 资源扩散慢，丢关键中塔 |

前期把等级和装备规划好，后期才有向上兼容的资格。
