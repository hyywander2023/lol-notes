# 后期团战先说清自己要什么保护

> 结论：后期先想清楚自己是输出位还是开团手，并直接告诉队友需要什么保护；输出不够就拖团等装备，别硬接。

## 开团前定三件事

| 要定 | 内容 |
| --- | --- |
| 站位 | 找能舒服持续输出的角度，别站窄口 |
| 定位 | 需要前排保护，还是要你去开团，先讲清楚 |
| 装备 | 输出不足就拖，等关键装备成型再接 |

## 地形与集火

| 地形 / 目标 | 处理 |
| --- | --- |
| 窄口坑里 | 别接，让阵容优势被地形抹平 |
| 开阔地形 | 利于拉扯，优先选 |
| 敌方关键输出 | 集火他，别盲目追坦克 |

队友开团手就位、核心输出有人保，再决定进不进。
