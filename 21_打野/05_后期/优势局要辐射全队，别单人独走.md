# 优势局要辐射全队，别单人独走

> 结论：自己肥了要让全队跟上——标信号带队友入侵、把中线资源分出去；单人深入对面野区，经济拉不开还会白送。

## 优势方三件事

| 动作 | 要点 |
| --- | --- |
| 主动指挥 | 自己发育好就标信号，带队友进对面野区 |
| 分配资源 | 中线让给队友，自己入侵敌半区 |
| 放弃低价值野 | 蛤蟆之类可放，集结中路打人数差 |

## 单干的代价

| 风险 | 后果 |
| --- | --- |
| 队友不在那侧 | 对面人多，你被抓死 |
| 资源扩散慢 | 关键中塔丢失，优势变不成胜势 |
| 视线只盯野怪 | 被对手牵着走，节奏断档 |

优势时选项多，但越想什么都管，越容易什么都做不好。
