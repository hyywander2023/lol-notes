# 中期出门先看三条线，中线是开关

> 结论：从基地出来别自动走最近的野怪，先看中线推出没有——中线没推，进河道、进野区、开资源都危险。

## 出门三看

| 看什么 | 判断 |
| --- | --- |
| 哪条线要进塔 / 没人接 | 需要你去处理或悬停 |
| 哪条线队友深推 | 你该去那侧做区域压迫 |
| 中线有没有推出 | 决定能不能转线、做视野、开资源 |

## 中线是地图开关

| 中线状态 | 后果 |
| --- | --- |
| 推出去 | 可进河道、进野区、转边线、做视野 |
| 被压回来 | 多数行动变危险 |

资源团常输在开团前：中线没推、视野没做，队伍只能脸探草丛。想控资源，先帮队伍拿中线。
