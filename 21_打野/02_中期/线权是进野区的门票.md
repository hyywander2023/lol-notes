# 线权是进野区的门票

> 结论：队友没线权就别进对面野区——那不是入侵，是把自己放进包围圈；线权是决策优势，不是免死金牌。

## 先看线权再做的事

| 行动 | 线权要求 |
| --- | --- |
| 争河蟹 / 开小龙 / 开巢虫 | 附近线上能先动 |
| 入侵 / 反野 / 做深视野 | 队友能跟上或牵制 |
| 河道打架 | 敌人离线会亏兵亏塔 |

## 有线权也要会撤

| 情况 | 处理 |
| --- | --- |
| 敌人先动，队友不动 | 撤，别硬打 |
| 队友被兵线锁住 | 敌方可支援你就不能贪 |
| 单排队友不跟 | 线权只给你选择权，不保证人来 |

敌人离线要付代价；你撤掉，他同样亏兵、亏经验、亏塔血。
