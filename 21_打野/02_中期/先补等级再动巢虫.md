# 先补等级再动巢虫

> 结论：缺等级时别急着动巢虫——它经验不高，先刷三组野补等级，等上中野能赢 3v3 再争。

> ⚠️ 版本差异：课程为旧叫法/旧数值（潮虫），2026 赛季为虚空巢虫 8:00 刷新，已按当前版本更新。

## 什么时候放弃巢虫

| 信号 | 判断 |
| --- | --- |
| 自己等级落后 | 补等级优先，巢虫经验不高 |
| 上路回家没状态 | 少了 3v3 的一环 |
| 中路正在推线 | 对面中单可能先支援 |
| 敌野刚在下半区出手 | 他可能转向上半区或入侵 |

## 正确顺序

刷完三组野 → 等队友上线 → 组织中路联动 → 再考虑巢虫。上中野 3v3 胜率更高时去争，比盲目开虫稳。刷完野区要有明确目标，别「有野刷野」刷到节奏迷茫。
