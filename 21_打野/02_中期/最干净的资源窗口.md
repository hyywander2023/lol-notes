# 最干净的资源窗口

> 结论：敌野在另一侧露头才是干净窗口；抓到人不等于能开资源，先按状态→兵线→敌野位置过一遍。

## 敌野露头另一侧

| 敌野露面位置 | 可考虑的己方资源 |
| --- | --- |
| 上半区 | 下半区小龙 |
| 下半区 | 上半区巢虫 / 先锋 |

敌野不在 ≠ 敌线上不来。如果附近队友回城、对面线上能先动，照样可能被包。

## 抓到人之后

顺序：队友状态 → 兵线 → 敌野位置 → 决定开不开。

抓人后的资源窗口很短；条件不满足，就去刷野、反野、做视野或回城，不要因为刚抓到人自动开龙。

## 终极判据

最干净的资源不是拼惩戒抢来的，是对面根本没资格来的时候拿的。
