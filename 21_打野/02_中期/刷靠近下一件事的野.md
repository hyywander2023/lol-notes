# 刷靠近下一件事的野

> 结论：中期刷野不是越满越好，而是刷靠近「下一件事」的野——小龙 5:00 就靠下半区，男爵 20:00 就靠上半区。

## 路线跟着下一件事走

| 下一件事 | 出门方向 |
| --- | --- |
| 小龙要刷 | 靠近下半区 |
| 男爵要刷 | 靠近上半区 |
| 中线要争 | 围绕中路附近野怪 |
| 队友深推边线 | 往那侧靠 |

## 野怪也有地图价值

| 野怪位置 | 价值 |
| --- | --- |
| 靠近中路 / 资源区 | 刷着也能随时支援中路、河道、资源 |
| 偏远野怪 | 可刷，但别为它错过关键地图时机 |

中后期要从「刷完所有野」切换到「刷靠近关键区域的野」。
