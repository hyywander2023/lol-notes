# 开资源前查五件事

> 结论：资源刷新不等于有资格开；五件事有一件不干净就别硬开，先制造优势再打资源。

> ⚠️ 版本差异：课程为旧时间点，2026 赛季小龙 5:00、巢虫 8:00、先锋 15:00、男爵 20:00 刷新，已按当前版本更新。

## 五件事清单

| 检查项 | 要确认什么 |
| --- | --- |
| 附近线权 | 我方线上能否优先支援 |
| 队友状态 | 血量、蓝量是否健康 |
| 敌野位置 | 敌方打野是否在附近 |
| 双方人数 | 人数对比是否占优 |
| 惩戒与关键技能 | 惩戒是否可用，大招是否冷却 |

## 先制造优势再开

优势来源：击杀或打残逼回城、推线拿线权并布好视野、确认敌野露头或敌方关键技能不在。没有优势就开资源，本质是赌博。

## 两个禁忌

- 队友没线权，自己开。
- 敌野没露头，硬拼惩戒。
