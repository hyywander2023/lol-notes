# 抓人前读意图，切入走侧后方

> 结论：抓人前先判断线上要做什么，再从侧后方封回塔路线；正面走过去，敌人后退就废了。

## 先读线上意图

| 线上状态 | 你的预判 |
| --- | --- |
| 要推线回城 | 会压线，是抓人窗口 |
| 卡线 / 抢等级 | 会停留，位置靠前可抓 |
| 守塔下大波兵 | 被锁在塔下，配合越塔 |
| 大波线刚进塔 | 易越塔也易被反蹲，先查敌野 |

## 切入与技能窗口

| 要点 | 做法 |
| --- | --- |
| 角度 | 侧面 / 后方出现，封住回塔路；正面只会吓退 |
| 控制顺序 | 稳定控先交，命中后接贴脸控，别同时交 |
| 技能窗口 | 记下对方闪现时间，抓没闪的人比抓满技能稳定 |

血量低不等于能抓，兵线位置、召唤师技能、队友控制才决定成败。
