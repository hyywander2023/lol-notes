# 围绕野怪刷新节奏行动

> 结论：进一个半区就把它刷完整；空窗期拿去抓人反蹲做视野，但别因此错过下一轮刷新。

## 半区清野是默认规则

| 半区 | 一次刷完 |
| --- | --- |
| 蓝区 | 蓝 Buff + 魔沼蛙 + 三狼 |
| 红区 | 红 Buff + 锋喙鸟 + 石甲虫 |

只刷一组就走的后果：走路时间变多，野怪刷新不同步——回头单刷亏时间，不刷又卡经验。

## 空窗期做什么

刷完一轮到下一轮之间：抓人、反蹲、回城、做视野、控河蟹、入侵、开资源、保护队友推线。前提是清楚下一轮什么时候刷。

## 节奏循环

刷野 → 空窗期做事 → 下一轮刷野 → 下一段空窗期。清野越快，空窗期越多，能做的事越多。

## 打断半区的例外

只有高成功率抓人、关键资源、反入侵、关键线，才值得打断半区节奏。
