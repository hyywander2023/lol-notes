# 第一轮刷向高波动线

> 结论：开局真正要定的不是红开还是蓝开，而是第一轮往哪条线刷——优先刷向高波动线。

## 什么是高波动线

更容易换血、压线、交召唤师技能、被抓或反蹲的线。

| 特征 | 判断 |
| --- | --- |
| 近战对近战 | 波动高 |
| 有一方带强控制 | 波动高 |
| 有强推线 / 强压制 | 波动高 |
| 双方都想抢等级 | 波动高 |

下路重点看辅助类型，辅助决定前期 2v2 主动权，不必记所有对位。

## 为什么刷向它

第一轮刷向高波动线，刷完更容易找到事做（抓人 / 反蹲 / 越塔），而不是站在野区发呆。

## 配合敌野情报

如果敌野也刷向同一侧，你去那边可能变成河道 2v2 或 3v3。开局路线不能只看线上，要结合一级侦查。
