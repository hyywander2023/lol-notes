# 反蹲用营地悬停，别挂机蹲

> 结论：反蹲不是站着等，是在高风险线附近正常刷野；对面来能反打，不来你也不亏时间。

## 最差的做法

朝里蹲十几秒什么都不做。除非空窗期，或非常确定对面马上来，否则别这么玩。

## 营地悬停四要素

| 场景 | 为什么适合悬停 |
| --- | --- |
| 队友大波线要进塔 | 对面必须来守，你能反蹲 |
| 队友压线但没视野 | 你就是那道保险 |
| 双方高爆发对线 | 一打起来就是机会 |
| 敌野大概率在这一侧 | 附近资源即将刷新 |

收益：自己有发育、队友推线更安全、敌野来抓可反打。中期队友推边线时同样适用——站在附近野区和河道形成区域压迫，不用跟他走到线上。
