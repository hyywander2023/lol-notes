# 用补刀数追踪敌方打野

> 结论：看一眼积分板补刀，就能推断敌野刷了几组、下一步去哪；追踪是为了决定你做什么，不是炫技。

## 补刀换算

| 观察 | 推断 |
| --- | --- |
| 每组野约 4 补刀 | 估算他刷了几组 |
| 露头时身上几个 Buff | 判断开野方向与流转 |
| 某半区野怪已空 | 他大概率去了另一边 |

## 三种画像

| 敌野类型 | 你的应对 |
| --- | --- |
| 规范全刷 | 按路线追踪，预判他下一站 |
| 单组乱抓 | 稳定刷野 + 反野惩罚他 |
| 漏了半区 | 判断他会不会来，提前做视野 |

带入对面视角：同样时间里他能刷几组、能不能回城、从哪走到哪。对面在上半区露头，你就看下半区资源。
