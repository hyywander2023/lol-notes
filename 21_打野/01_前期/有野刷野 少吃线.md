# 有野刷野 少吃线

> 结论：前期有野就别吃线，队友能吃的线不要抢；中期队友不处理时，才主动推线。

> ⚠️ 版本差异：课程为旧数值，2026 赛季小兵 0:30 出发，红蓝 Buff / 三狼 / 锋喙鸟 0:55，石甲虫 / 魔沼蛙 1:07，已按当前版本更新。

## 前期：有野刷野

- 前期打野吃兵有经验惩罚，花时间吃一波并不划算。
- 你的野怪还在刷，宠物任务也需要推进。
- 例外：兵线进塔没人管，或必须帮队友处理回城线。

## 中期：可主动推

经验惩罚下降、清线变快；队友没人处理时，可以更主动推线。

## 吃线三问

| 问题 | 判断 |
| --- | --- |
| 这波线队友能不能吃？ | 能吃就别抢 |
| 吃完能不能制造地图压力？ | 推塔 / 拿龙 / 入侵才算好线 |
| 会不会耽误更重要的资源？ | 耽误就不吃 |

好线是修正地图状态，坏线只是为自己贪钱。
