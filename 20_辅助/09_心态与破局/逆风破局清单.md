# 逆风破局清单

> 结论：劣势局不是「稳住」，是**主动放弃一半地图，把回合差攒回来**。辅助是劣势局最先能做出回合差的位置。

## 四步

| 步 | 动作 | 判据 |
| --- | --- | --- |
| 1 | 放弃守不住的塔 | 「这个塔反正都要掉，不如早点给，我们去游走」 |
| 2 | 锁死对面雪球 | 让对面 AD 只吃塔下线，吃不到人头滚雪球 |
| 3 | 视野只做半边 | 上半区直接放弃，「宁愿让他一片黑」 |
| 4 | 抓对面的贪 | 打完资源不回城、贪一波兵线就是你的机会 |

## 兵线怎么放

| 局面 | 处理 |
| --- | --- |
| 塔要掉 | 提前放弃，换一次游走 |
| 对面 AD 有优势 | 把线放回来，让他只能吃塔皮 |
| 兵线卡在自家塔前 | 这是最好的状态——对面压深就打野好抓 |
| 被针对到掉线 | 把炮车线卡住，「只要不进塔就还有的玩」 |

## 视野怎么做（关键）

劣势局做视野的优先级和优势局**相反**：不要追求覆盖，只追求「不被绕后」。

- 唯一的防守眼放在**对面打完资源后会绕的那个口**；
- 上半野区直接点亮，因为对面打野大概率在上；
- 做不进去就改埋伏：「他们谁做视野谁死，卖破绽等他们来」。

## 抓回合差的三个动作

1. **算打野**：对面下半区没资源了 → 打野大概率去上 → 提前反蹲。
2. **算回城**：对面辅助回家你不回 → 你领先一个回合（多做一次视野或一次游走）。
3. **算兵线**：我方兵线进塔 → 下波必回推 → 这 20–30 秒是你的自由时间。

## 团战翻盘点

- 对面单带阵容：不要接单带的节奏，**主动把局面推向团战**；
- 对面 C 位很肥：等他走位脱节，或用控制链把他从阵型里拉出来；
- 换人头是赚的：「劣势方换人头完全可以接受」，二换二也不亏。

## 承认失误的正确姿势

复盘的落点必须是「下次站哪」，不是「下次注意」。

> 原话：「这波身位应该往河道当人形视野，不应该压这么深。」——这句是有用的；「下次注意」是没用的。
