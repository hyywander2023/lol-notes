# 惩罚技能冷却：最稳的换血窗口

> 结论：对面关键技能一空就立刻前压，用普攻和站位惩罚；没技能的人不该被你放过。

## 五个前压信号

| 信号 | 含义 |
| --- | --- |
| 钩子空 | 硬辅失去起手，前压安全 |
| 控制空 | 对方没有反打手段 |
| 护盾交 | 保护真空，集火窗口 |
| 位移用掉 | 无法拉开，可逼线 |
| 强消耗打在小兵上 | 蓝和技能都空，白嫖一波 |

## 主动骗技能

站到对方技能边缘前后移动引诱出手，空了再向前进打。对线不只拼命中率，更拼谁更懂冷却时间——**技能空了不是停止压制，是开始压制**。

## 三个类型都能用

远程辅助用来白嫖普攻，法师辅助提高命中，硬辅判断对方站位是否过深。按类型不同，但"等关键技能空再动手"对所有辅助都成立。
