# 视野线决定你能插多深

> 结论：不在不属于自己的区域独自做眼——先推线、确认敌人位置、让队友靠近，再把黑暗区域变成可进入区域。

## 视野线是什么

视野线 = 你们当前能安全控制的地图层级。优势就往敌方半区推，劣势就退回自家野区入口。影响因素：兵线、防御塔、队友位置、敌方是否露头、下一个资源点。

## 三个安全窗口

| 窗口 | 为什么安全 |
| --- | --- |
| 推线后 | 敌人被迫处理兵线，位置暴露 |
| 打赢团/推完塔后 | 撤退前顺手做，反正要回城 |
| 敌方多人露头或死亡时 | 关键人物不在，可推进视野线 |

## 做眼前四问

谁能杀我？他现在在哪？队友能不能跟？这颗眼是为下一个资源，还是无意义探索？——答不清就别一个人进黑区。
