# 控中路优先

## 核心

**中路是地图枢纽。把中路线推过去，再围绕小龙 / 大龙做视野。**

## 为什么

中线推过去 → 敌人被锁在高地 → 资源更容易白拿。

具体机制：

1. 中线优势 = 两侧野区视野可以安全铺。
2. 敌人被压在高地 = 无法前置站位，抢龙时间窗被压缩。
3. 你的队伍可以自由选择"打龙"或"抓落单"，两件事都不亏。

## 操作顺序

先推中线 → 再进对面野区做视野 → 再决定打龙 / 抓人。

**顺序不能反。** 中线没推就进野区做视野，很容易被对面反打。
