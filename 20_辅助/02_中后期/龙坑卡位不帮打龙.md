# 龙坑卡位：辅助不帮打龙，去卡路口

> 结论：打龙时辅助伤害有限，别站在坑里帮打——点完路口视野后卡在必经位，逼对面进不来。

## 辅助在龙团的活

| 该做 | 不该做 |
| --- | --- |
| 保证龙坑路口视野全亮 | 站在坑里帮打龙（伤害有限） |
| 视野做完再站卡位 | 视野没做完就进坑，站位无效 |
| 对面来了就往后退，保持压力 | 站太深被开 |

## 卡位怎么做

点完视野后在关键路口站定，观察对面动向，适时退到安全位置——目的是让对面开不到你，但吃到路口压力不敢过来。有闪现时可在草丛埋伏找开团机会。

## 视野顺序

中期争资源时中线最重要，先守住对面推过来的中线，再谈野区视野。大龙未刷新、你又比对面晚到时，别急着一进坑就做视野，先守住中线再行动。
