# 辅助也有 1v1 能力

## 认知纠正

不要默认自己没有战斗力。

## 能单杀的对位

| 你的类型 | 能打的目标 |
| --- | --- |
| 坦克辅 | 脆皮法师 |
| 爆发辅 | 无位移 AD |

很多情况辅助可以单杀，尤其是对面落单、状态不满、技能不全的时候。

## 判断标准

- 对面没有位移 / 没有保命技能 → 可以打
- 对面血量低于你一套爆发 → 可以打
- 对面技能 CD 空着 → 可以打
