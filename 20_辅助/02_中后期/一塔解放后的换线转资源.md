# 一塔解放后的换线转资源

## 错误做法

拿下一塔之后继续死蹲下路，原地坐牢。

一塔的意义不是"完成了一个任务"，而是**下路对线阶段结束，你的兵线义务解除了**。继续留在下路是纯浪费。

## 滚雪球路线

```
下塔推掉
  → 和 AD 换线去中路
  → 拿小龙
  → 转上路拿上塔
  → 控先锋 / 虚空虫
  → 同时在敌方野区铺连续视野线，抓落单
```

## 顺序为什么是这个

1. **先去中路**：中路是枢纽，推过去才能解锁两侧资源。
2. **再拿小龙**：控地图下半区，同时保证视野线。
3. **再上塔 + 先锋/虫子**：把上半区也解锁，形成双线压制。
4. **视野线同步铺**：不是拿完资源再造视野，而是造视野 → 抓落单 → 白拿资源。

## 关键心态

一塔之后你的身份变了：从"下路辅助"变成"**地图辅助**"。哪里有资源、哪里有节奏，你就在哪里。
