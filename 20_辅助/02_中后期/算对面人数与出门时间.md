# 算对面人数与出门时间

> 结论：进野区、接资源前先数对面几个人、几点出门，人数劣势就果断换资源别硬接。

## 时刻算人数差

做每个行动前先判断会不会有人数差：对面有人在上路露头，野区最多就一个打野。人数劣势时不进黑视野、不强行开团，果断换资源或撤退。敌方在资源点的人数不占优时，可以用信号指挥队友一起行动。

## 算对面几点出门

| 情况 | 怎么算 |
| --- | --- |
| 有人阵亡 | Tab 看复活时间，对比谁先复活 |
| 无人阵亡 | 看中线线权：你先推完先回，对面要接完线才能回，就比你晚出门 |
| 参考 | 兵线状态能看出对面回城时间点 |

算出对面晚出门，就抓时间差先动视野或资源；对面先出门，就别去黑视野区域硬碰。

## 一个原则

中野辅往下走时，没队友在身后别进黑视野——被蹲一次，视野和资源连锁全丢。
