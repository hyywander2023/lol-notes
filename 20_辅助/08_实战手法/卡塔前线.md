# 卡塔前线

> 结论：把兵线卡在**自家塔前但不进塔**，一次同时拿到三样东西——对面不能回城、打野好抓、自己最安全。

## 三个收益

| 收益 | 机制 |
| --- | --- |
| 对面不能回城 | 兵力在他塔前，他回家就掉一整波经验与镀层 |
| 打野好抓 | 对面压深，绕后路线长，极易被抓 |
| 自己最安全 | 你退一步就是塔，对面开你＝抗塔 |

> 原话：「只要保持好状态，把兵线一直卡在塔前，对面就会很难受；对面不想让我卡线，上来 A 我，那他就卖破绽。」

## 怎么卡

1. **只补最后一刀**，不要 A 兵推线；
2. 我方小兵数量略多于对面（多 2–4 个）时，兵线会自然停在塔前；
3. 对面强行推线时，用技能清掉后排兵，让兵线停在塔外；
4. 己方 AD 补刀帧前压，把对面辅助赶开，防止他破线。

## 什么时候放弃卡线

| 情况 | 处理 |
| --- | --- |
| 兵线已经进塔 | 转成塔下补刀，辅助去河道做眼 |
| 对面辅助消失 | 立刻推线，不留在塔前挨包夹 |
| 打野在下半区且要越塔 | 提前把线推出去，制造回推线 |
| 己方 AD 血线危险 | 放弃卡线，回城换状态 |

## 卡线的两个变体

**卡住不让回家。** 对面 AD 残血想回城时，卡住兵线并持续施压，逼他要么丢兵回城、要么留下吃线——两种都赚。

**打断回城。** 用远程技能打断对面辅助回城，让他和 AD 不同步，你就领先一个回合（见 [[单排辅助带节奏]]）。

## 一个反面

卡线卡到自己掉血过多，是亏的。判断标准：**卡这一波掉的血，能不能换来对面一波兵的经验差**。换不到就不卡。
