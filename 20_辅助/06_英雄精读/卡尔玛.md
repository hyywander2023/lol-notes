# 卡尔玛（Karma）

> 一句话定位：**进攻软辅的代表**，靠 Q 兵溅射拿线权，靠 R 强化打前期压制。

## 强度曲线

| 1 级 | 3 级 | 6 级 |
| --- | --- | --- |
| 强（抢先上线直接前压） | 强（RQ 爆发） | 中（后期作用下滑） |

定位说明：「在钻石分段以及低分大师，卡尔玛是个不错的选择」——**吃前中期节奏，不能拖**。

## 怎么用

### 对线

- 队友不跟抢草就不要贸然抢：走上面，时不时靠河道，避免被绕后。快到 1:15 再发信号抢。
- 和 AD **分开站位**（对面 Q 只能打到一个）。
- 核心换血公式：**Q 兵溅射打人**——在兩個小兵的空隙之间找角度，同时打到人和兵。
- 站到小兵前面给压力，对面会很难受。
- 开人判据：看对面辅助站位和技能等级（「露露只有两级 E，这时候就可以上去打」）。

### 技能与 R 的三种用法

| 强化 | 用途 |
| --- | --- |
| RQ | 消耗/爆发/推线 |
| RW | 回血＋勾引（「R 好了就上去卖一下，让他打我，再 RW 回血」） |
| RE | 群体护盾＋加速，反打与撤退 |

**省冷却技巧**：在草里提前开 R，能省几秒 R 的时间；二段 W 链也能减 R 的 CD。

### 兵线与节奏

- 该推就推：兵太多控不住，一定要多推掉几个才能控。
- 靠兵线算等级：「还差两个小兵到 2 级，可以直接前压」。
- 推进去让兵线重置，把线放出来更好打优势。

### 游走

- 「辅助如何辐射三路」是她的强项：帮中反蹲＋解线＋做视野三件事一起做。
- 打野在哪我在哪——「对面打野在哪，这盘我就在哪」。
- 算下一步：敌方下半区没资源了 → 打野大概率来上 → 提前去上反蹲。

### 视野

真假眼配合：在关键口子点真眼，直接看到对面打野；回家把扫换成眼，多两颗视频眼。

## 对面选她（限制清单）

| 手段 | 说明 |
| --- | --- |
| 别在草里跟她抢 | 正常抢草一定被拉扯，改从河道上线 |
| 先骗掉 Q 再动手 | 她 Q 一空就只剩 W 和 E，贴脸可直接打 |
| 抓 Q 空窗 | 「卡尔玛空 Q，果断前压」 |
| 用等级差打 | 你 3 级她 2 级＋你有装备优势，这是最好的窗口 |
| 给她假视野 | 她要排真眼时给假视野，绕回来再打 |
