# 派克（Pyke）

> 一句话定位：**钩＋突进＋斩杀的刺客型辅助**。他的全部威胁都压在一发 Q 上——Q 空就是废物。

> ⚠️ 素材说明：本批次 5 期派克相关视频**全部是「对面选派克我怎么打」**，没有一局我方玩派克的教学。因此本篇以「怎么限制他」为主，「怎么用」只写能从对手视角反推的行为模式。

## 强度曲线（从对手视角）

| 1 级 | 3 级 | 6 级 |
| --- | --- | --- |
| 强（必抢中草，Q 抽奖） | 强（Q＋E 强开） | 强（R 斩杀滚雪球） |

## 他的固定行为（反推出来的）

- 一级必抢中草/开扫进中草；
- 兵线没优势时占草毫无意义，会退草；
- 进草大概率在续 Q；
- 游走节奏点：Q 空即窗口、E 闪强开、W 隐身转中；
- 复活后如果下路不需要他，大概率直接去中。

## 对面选他（限制清单·本篇主体）

| 手段 | 具体做法 |
| --- | --- |
| 站兵后 | 「我就站在小兵后面，我满血，你能干嘛」——他带扫进中草也没用 |
| 一级防草 | 默认他抢中草，3–4 秒往中草丢技能试探；他开扫就发撤退信号，让 AD 站一草后面（不是顶端） |
| 抓 Q 空 | 「派克在蓄力 Q，只要这个 Q 空了，我们就有机会」——Q 空立刻上 |
| 他进草就扭 | 「派克进草大概率会续 Q，脚走位向上扭，骗掉 Q 就是机会」 |
| 出草 A 再进草 | 出草 A 人立刻进草卡视野，让他 Q 不到你 |
| A 兵平线 | 「只要你会 A 兵平线、抓对面 AD 补刀时机换血，线迟早是你们的，派克迟早会退草」 |
| 卡线废他 | 线卡住他不好游走，对面打野也不好帮他们抓 |
| 不跟他游 | 「不要当跟屁虫去中，此时不知道敌方打野位置，很可能被埋伏」——改成推线 |
| 他没 E 就死 | 「派克这波没 E 的，那他又死了」——E 交完就是脆皮 |
| 选角 | 索拉卡是「软辅里面最好打派克的英雄」；硬辅可用塔姆解 |
| 出装 | 打派克基本可以无脑 CD 鞋；第一波回家把扫换眼 |

## 一个通用原则

「高手软辅其实不怕钩子英雄，怕的是对面打野抓下配合钩子 GANK。」——**打派克真正要防的是他的队友**。

## 素材缺口

- 无我方派克局：不知道他的斩杀线计算、E 闪的角度、W 的使用时机。
- 无具体数值（R 斩杀线、Q 蓄力时间）。
