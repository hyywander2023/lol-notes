# 米利欧（Milio）

> 一句话定位：软辅里保护性最强的一档——自带「移动泉水＋群体水银」，靠 Q 打断硬辅的突进。

## 强度曲线

| 1 级 | 3–4 级 | 6 级 |
| --- | --- | --- |
| 看对位：打一级弱势 AD 可点 Q 压；打泰坦一级学 Q | **强势点**，Q 伤害成型 | 有 R，但**不是免控**，被控就开不出来，也解不了击飞 |

## 怎么用

### 对线

- 站位：AD 前面约一个身位，**不平行、不并排**；AD 前压时身位一起前顶。
- 抢草：1:05–1:10 开扫抢中草；走直线不贴墙；开局走上侧避免中野绕后。
- 占草要循环：「出草给压力 → 回草屏蔽视野 → 回程中 A 兵」，不在草里静止。
- **打蕾欧娜**：她 E 就 Q 打断，敢给身位、多偷 A（她急了就会空交）。
- **打泰坦**：带骸骨＋守护者，吃钩第一波也打得过；他没钩时发信号让 AD 前顶。
- **打莎弥拉**：被开了不要立刻交 Q，等她交 W 之后再 Q 击退。
- **打洛**：没 Q 就不能出草（会被秒），没 Q 时把三草让给他。

### 技能时机

| 技能 | 关键点 |
| --- | --- |
| Q | 打断硬辅突进是核心价值；也能 Q 小兵溅射消耗（「溜溜球」）；Q 中英雄返还部分蓝 |
| W | 给 AD 回血＋加射程；越塔时给塔下队友；五级 W 收益明显 |
| E | 给自己触发被动增伤，或给 AD 触发香炉/艾黎盾 |
| R | **必须提前开**（提供韧性＋回血），解控留给寒冰 R、蚂蚱 R、锤石钩这类硬控 |

### Q 打断成功率的三条规律（原话整理）

| 时机 | 结果 |
| --- | --- |
| 双方同时 Q | 成功 |
| 对手先 Q，你再 Q | 成功 |
| 你先 Q，对手后 Q | 失败，会被 A 到 |

特殊：锤石要在他 Q 命中的**瞬间**交 Q（二段就过不来）；洛要在他圈判定出来**之前**交。

### 越塔顺序

兵线进塔 → 先走上去让对手交技能 → 等他交完 → E 给自己 → 击退 → R 回血拉出塔。

### 兵线与游走

- 炮车线尽快处理掉；用 Q 小兵加快进塔，**不让对面回家**。
- 慢推比快推更难受；推太快就等下一波重置。
- 第四波线的前两个近战兵升 3，Q 溅射可以抢这个点。
- 游走不必击杀：帮中解线、逼对面中单吃压力都算；路线走上侧（中单会防下半区）。

### 团战

第二、第三身位，绝不站第一身位。R 提前开，解控只留给关键技能。

## 对面选他（限制清单）

| 手段 | 说明 |
| --- | --- |
| 等 Q 空 | Q 冷却长，空窗期就是他唯一的破口 |
| 抓 W 交完 | W 冷却极长且蓝耗高，交完立刻压 |
| 别站 Q 直线 | Q 是直线技能，侧向站位能规避 |
| 硬辅先骗 Q 再进 | 他 Q 在手上时，任何突进都会被打断 |
| 他没闪时集火 | 无位移，被贴脸只能交 R |
