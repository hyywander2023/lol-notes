# 机器人（Blitzcrank）

> 一句话定位：**一发定生死**。Q 中了是开团，Q 空了是废物——所以打他就是「骗掉那一发」。

## 强度曲线

| 1 级 | 3 级 | 6 级 |
| --- | --- | --- |
| 强（Q 约 20 秒，抢二强） | 强 | 强（Q 开团＋R 静电场） |

## 怎么用

- 占草要「出草给压力」，不要站在草里不动；先从草边规避他的 Q，再前压。
- 抢二节奏：开局不 A 工资装，留到第二波兵再用（这样比对面先到 2）。
- 开人手法：海克斯闪触发加速＋W 加速，预判对面 AD 回头走位出 Q；Q 拉回来接 E 击飞，需要破盾时接 R。
- 心法：「玩钩子的英雄一定要学会声东击西」——假装钩一个，实际钩另一个。
- 顺序纪律：「一定要先做视野再压人」。

## 对面选他（限制清单）

| 手段 | 具体做法 |
| --- | --- |
| 站兵堆 | 「必须站在兵堆，不给敌方任何机会」；他往上站你就站兵堆下面 |
| 按 S 骗钩 | 站兵堆外按 S 做卡住的假象，钩出瞬间回兵堆 |
| 假 A 骗钩 | 站最右侧小兵处假装 A 对面 AD，实则后拉 |
| 别无脑抢草 | 对面中野也有控时不要抢，45 秒后再抢 |
| 带眼不带扫 | 「带眼不是为了防守，是为了更好的进攻」 |
| Q 空就反打 | 「机器人勾空我们就顺势反打」；一级 Q 约 20 秒 |
| 有兵线优势他自退 | 「有了兵线优势，他们自然就退草了」 |
| 他把草让给你也行 | 他硬占草就放弃草权，用兵线从他上侧消耗 AD |
| 主动吃钩当跳板 | 站 AD 前面给他勾，勾完反手打 AD，治疗加速 |
| 符文 | 骸骨＋坚定提高第一波吃钩容错；守护者打硬辅也可带 |

## 关键认知

> 原话：「高手软辅其实不怕机器人这个英雄，怕的是对面打野抓下、配合机器人 GANK。」

也就是说：机器人的真实威胁来自他的队友。打他真正要做的是**眼位和身位**，不是躲钩技巧。

## 出装/符文（原文口径，仅供参考）

> ⚠️ 版本差异大：出现「选民/四速鞋/冰心」等口径，装备名以当前版本为准。

- 决策逻辑：对面减速多 → 优先高移速鞋；对面有强控中单 → 第二件解控类装备。

## 素材缺口

- 没有被动护盾、R 静电场范围的具体数值；没有「他先手 R 开团」的应对段落。
