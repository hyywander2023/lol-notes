# 岩雀（Taliyah）

> ⚠️ **素材说明：本批次 279 个视频里，岩雀全部以「敌方打野」或「我方打野」出现，没有一局辅助位岩雀的教学。** 因此本篇不是英雄攻略，而是「**当下路遇到岩雀时怎么做**」的防守卡，以及她的节奏点。

## 已知节奏点

| 时间 | 行为 |
| --- | --- |
| **4 级** | 岩雀四级抓下是固定节奏点，「此时占草有危险」 |
| 有 R 后 | 墙体分割战场，可强行切断退路 |
| 有 E（撒石阵）时 | 阵内不能站人，走位要绕开 |

## 遇到她时怎么做

| 手段 | 具体做法 |
| --- | --- |
| 4 级别死占草 | 「此时是岩雀四级抓下时间点，占草有危险，站在小兵旁边迷惑对手」 |
| 身位靠河道 | 「身位应该往河道靠，岩雀一露头我们第一时间就该知道」 |
| 躲 W（岩突） | 「AD 走位把岩突躲了，那就死不了了」；走位一定不能停 |
| 绕开石阵 | 「岩雀有撒石阵的，让队友走上面，我们走下面」 |
| 明牌在上才敢压 | 确认她在上半区 → 下路没压力，可以继续压/越塔 |
| 她可能抓中 | 她不在下路且我方中路在压线 → 改成去中路反蹲 |
| 打断 R | 蕾欧娜 Q/E、任何硬控都能把她从墙上打下来——「岩雀开大，我们 Q 直接让她下车」 |
| 帮 AD 挡 | 「在闪 Q 岩雀的同时往 AD 脸上走，帮他挡岩雀的 Q」 |
| 反制游走 | 她露头就抓上/守上半野区 |

## 为什么还是保留这张卡

她虽然不在辅助位，但**是下路最常见的打野威胁之一**（279 个文件里出现 115 次），而「4 级抓下」这个时间点直接决定你什么时候能压线。这条信息在本库其他位置没有。

## 素材缺口（严重）

- 完全没有辅助位岩雀的对线内容；
- W 抬的判定范围、E 石阵持续时间、R 墙体长度与持续时间全部无数值；
- 她的辅助出装、符文、加点一概缺失。

> 建议：这张卡暂时按「对手威胁卡」使用；如果后续批次有辅助岩雀的素材，再补成完整英雄卡。
