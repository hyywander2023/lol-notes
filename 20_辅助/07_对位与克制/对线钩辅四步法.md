# 对线钩辅四步法

> 结论：打钩辅不是「躲钩」，是**把他的钩变成废技能，然后用空窗期压他 15–20 秒**。

## 四步

| 步 | 动作 | 关键 |
| --- | --- | --- |
| 1 | 站兵堆/小兵正后方 | 钩子穿不过小兵，这是第一层防线 |
| 2 | 在「能立刻回兵堆」的距离卖破绽 | 超出这个距离就是送 |
| 3 | 钩空 → 立刻前压 | 锤石 Q 约 19 秒、机器人 Q 约 20 秒 |
| 4 | 卡线，不让他回城 | 他回家＝你领先一个回合 |

## 卖破绽的三种手法

| 手法 | 操作 |
| --- | --- |
| 假 A 真走位 | 抬手要 A，取消后侧向走位（见 [[假A真走位骗技能]]） |
| 按 S 停顿 | 站兵堆外按 S 做"卡住"假象，钩出瞬间回兵堆 |
| 小兵左右晃 | 在己方小兵左右横移，不出兵线 |

## 主动吃钩也是选项

血量健康、对面 AD 爆发不够时，**主动站在 AD 前面吃钩**，把钩当跳板：

> 原话：「走到 AD 前面给机器人勾，勾完后 Q 不用给机器人，直接反手打寒冰，利用机器人的勾当跳板，治疗加速。」

前提：带骸骨＋坚定，且我方 AD 能跟上输出。

## 符文的通用解

打钩辅带**骸骨＋坚定**：坚定在被控/减速时提供双抗，专门填走位失误。守护者在当前版本打硬辅也可带。

## 三条判断

| 情况 | 处理 |
| --- | --- |
| 他学了钩子且你技能不全 | 放线、退一草，等 CD |
| 他学了 E/护盾（有反手） | 别硬压，先骗反手 |
| 对面辅助消失且中路在压线 | 默认他去抓中，去中路反蹲，不要追 |

## 常见错误

- 只会退，不敢用空窗期 → 对面钩子好了又来一轮；
- 站太远「安全」→ 钩子空窗期也没压到，等于白等；
- 用位移抢草 → 位移一交，钩子就中了。
