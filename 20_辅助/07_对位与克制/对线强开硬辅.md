# 对线强开硬辅

> 结论：强开辅的杀招是「突进＋控制链」。破法只有三条：**让突进打空、让控制链接不上、让他在没有兵线的时候开**。

## 他的开人条件（你要逐条拆掉）

| 条件 | 拆法 |
| --- | --- |
| 兵线在他那边 / 你压深 | 把线卡在自家塔前（见 [[卡塔前线]]） |
| 你的位移/闪现已交 | 位移留着，不要用来抢草 |
| 你在补刀帧 | 补刀前先看他的位置，别低头补 |
| 他技能全在 | 记他的 CD，空了就是你的窗口 |

## 三种拆法

**1. 阻挡/打断突进。** 米利欧 Q 可以打断泰坦 Q、蕾欧娜 E、芮尔 W、牛头 WQ 二连等；这一条决定了「米利欧为什么克制硬辅」。

**2. 站位拉到他的技能边缘外。** 蕾欧娜 E 有距离上限，站在射程外半步，他要么不开、要么开空。

**3. 卡视野反打。** 他突进时必须沿直线过来，你在草里/兵后等他落点，落地瞬间集火。

## 打不过时的标准姿势

| 动作 | 说明 |
| --- | --- |
| 放线，把草让给他 | 只玩一草，不争中草 |
| 兵线卡在塔前 | 他压深就打野好抓 |
| 不主动换血 | 等他自己交技能 |
| 伤害全打 AD | 硬辅血厚，打 AD 才有收益 |

## 硬辅的弱点清单

- 一级弱、需要等级（2–3 级才有完整控制链）；
- 技能全在后进入长空窗，且没有任何自保；
- 站在塔前时不敢开（抗塔＋被反打双输）；
- 被风筝时摸不到人，只能挨打。

## 关键提醒

硬辅最怕的不是被躲，是**开了但没杀掉**。你只要做到"他没杀掉人"，这一波就是他亏——他的技能进 CD，你的兵线还在。
