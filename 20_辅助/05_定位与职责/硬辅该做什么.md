# 硬辅该做什么

> 结论：硬辅的核心动作是**等**——等兵线到塔前、等对面交技能、等自己 CD。找机会开团是结果，不是任务。

## 开人四前置（缺一条就别上）

| 前置 | 判据 | 不满足会怎样 |
| --- | --- | --- |
| 兵线在己方塔前 / 能卡住 | 对面压深、不能回城 | 在对面塔前开＝送 |
| 对面关键技能已交 | 位移、控制、净化 | 被躲开后你站在人堆里 |
| 对面在补刀帧 | 抬手打小兵 | 有走位空间，勾不中 |
| 自己与 AD 都在 | AD 跟得上、有闪有治疗 | 开了没人跟，白送血 |

对面有位移时**先逼技能再开**：EZ 有 E、女警有 E、卡尔玛有 Q，不交就不要交自己的进场技。

## 三条日常动作

**卡塔前线。** 兵线卡在自家塔前＝打野最好抓、对面最难受、自己最安全。见 [[卡塔前线]]。

**站岗与卡位。** 站在路口/三角草口，替打野和中单挡信息。硬辅的血量是资源，该花就花——「我们死了就死，只要 AD 拿头就是赚」。

**造回合差。** 打断对面辅助回城，让他和 AD 不同步；对面辅助回家你不回，就领先一个回合。

## 控制链纪律

- 控制不要重叠：**等前一段控制快结束时再接下一段**（芮尔的 Q 二段拉、蕾欧娜 R 快结束再接 Q）。
- 泰坦这类：**QR 接普攻**对面交不出闪，**QA 再 R**对面就能闪走——顺序决定成败。
- 越塔起手用**平 A**，不要抬手给对面闪避空间，否则抗塔的会变成 AD。

## 打不过硬辅时

对面先手能力更强（德莱文＋泰坦、EZ＋卡尔玛）时改成：

1. 放线，把草让给对面，只玩一草；
2. 兵线卡在塔前，等对面逼身位再退；
3. 不主动开，等对面技能空窗反打。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 一级乱开远程辅助 | 被白耗，2 级前就掉半血 |
| 在对面塔前开 | 抗塔＋被反打，双输 |
| 技能一好就上 | 对面有闪有位移，永远差一点 |
| 开完就站着 A | 吃满反手，脱不出来 |
