# 辅助五分法

> 结论：辅助按**「靠什么给 AD 制造优势」**分五类——软辅给增益、消耗辅给压力、保护辅给容错、硬辅给控制、钩子辅给单点击杀。分类不是给人贴标签，是**开局就知道自己这一局的活在哪、对面那一局的破口在哪**。

## 一、五类定义与代表

| 类型 | 代表英雄 | 核心资源 | 一句话本质 |
| --- | --- | --- | --- |
| 软辅 | 众星之子（索拉卡）、仙灵女巫（璐璐）、风暴之怒（迦娜） | 增益与续航 | 让 AD **变强** |
| 消耗辅 | 光辉女郎（拉克丝）、万花通灵（妮蔻）、天启者（卡尔玛） | 手长与线权 | 让 AD **好补刀** |
| 保护辅 | 瓦罗兰之盾（塔里克）、弗雷尔卓德之心（布隆）、河流之王（塔姆） | 反应与容错 | 让 AD **死不了** |
| 硬辅 | 蕾欧娜、熔铁少女（芮尔）、牛头酋长（阿利斯塔） | 控制与坦度 | 让 AD **能跟上** |
| 钩子辅 | 蒸汽机器人（布里茨）、魂锁典狱长（锤石）、深海泰坦（诺提勒斯） | 单点判定 | 让 AD **收人头** |

## 二、优缺点对照

### 软辅

| | 内容 |
| --- | --- |
| 优点 | 给 AD 加攻击力／攻速／移速，给盾给奶；技能与自身攻击距离长；中后期装备成型后对 AD 的提升极大 |
| 缺点 | 身板脆、耗蓝多，容易被打残或击杀；无控制、无位移，留人能力差；没蓝时近乎无作用 |

### 消耗辅

| | 内容 |
| --- | --- |
| 优点 | 手长、前期技能基础伤害高；配彗星打高消耗；对线压制力强，前期小规模团战伤害不弱 |
| 缺点 | 自保差、身板脆，易被集火秒；**必须前期打出优势**，中后期经济跟不上就乏力 |

### 保护辅

| | 内容 |
| --- | --- |
| 优点 | 保护能力极强，以反打为主；给射手干净输出环境；不吃经济；对高爆发、强开、突脸阵容优势明显 |
| 缺点 | 手短、部分英雄笨重；先手技能空了会被追着打；**技能真空期长** |

### 硬辅

| | 内容 |
| --- | --- |
| 优点 | 控制极强、先手开团出色；不吃装备；血量坦度高不易死；留人能力强，技能不空则控制拉满 |
| 缺点 | CD 长，空技能后几乎丧失还手能力；**必须时刻看队友位置**，队友跟不上则适得其反 |

### 钩子辅

| | 内容 |
| --- | --- |
| 优点 | 钩中配射手前期爆发高，敌人半血勾中即斩杀线；先手勾到对面 AD，对面几乎没有还手能力 |
| 缺点 | CD 长，空钩会被追着打并失去主动权；多数情况需要预判走位 |

## 三、两组最容易混的区分

### 软辅 vs 保护辅：都叫"保护"，作用对象不同

| | 软辅 | 保护辅 |
| --- | --- | --- |
| 作用对象 | **队友身上**（buff 化） | **对面的威胁上**（拆解） |
| 典型动作 | 给盾、给奶、加攻速移速 | 挡技能、吃人、开无敌、举盾 |
| 生效前提 | 队友还活着且在输出 | **已经有人要挨打了** |
| 怕什么 | 被贴脸、没蓝 | 没挨打就没有用武之地；先手空窗 |

一句话：**软辅让 AD 变强，保护辅让 AD 不死。** 索拉卡奶得再多也救不了被一套秒的 AD，塔里克的无敌也换不来线权。

### 硬辅 vs 钩子辅：都是前排，进场的确定性不同

| | 硬辅 | 钩子辅 |
| --- | --- | --- |
| 进场方式 | 指向性（蕾欧娜 E）或必中组合（牛头 WQ） | 需要命中的判定（钩） |
| 方差 | 小——进得去就有控 | 大——命中即赢，空钩即废 |
| 空窗代价 | 中等（控没了但人还在） | 极高（无输出、无留人、被反追） |
| 对阵思路 | 拆他的进场路径（挡位、卡距） | **记 CD，在空窗里打** |

> 硬辅的强度写在技能说明里，钩子辅的强度写在**对手的走位上**。

## 四、和「辅助的三个档次」不是一回事

[[辅助的三个档次]] 讲的是**水平**（同一类里你打得好不好），本篇讲的是**工具**（你手里是什么、对面是什么）。两者正交：

- 拿索拉卡打成"移动泉水"，是档次问题，不是分类问题；
- 拿塔里克去开团，是分类问题——保护辅本来就不该负责先手。
