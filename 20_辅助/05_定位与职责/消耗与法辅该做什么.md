# 消耗与法辅该做什么

> 结论：消耗辅的活是**用线权换先动权，用蓝量算这一波能不能打**。压不死人就换战场，不要在原地磨。

## 消耗的两个前提

1. **对面没有反打手段**。卢锡安没 E、泰坦没 Q 时才是抽奖窗口——这时候 Q 空了也不亏，因为对面也没法进攻。
2. **自己的蓝够打完这一波**。蓝量只够一个技能就躲一草；够两个技能才压上去。

> 原话：「这个蓝量我们只能放一个技能的，躲在一草就好了；蓝量到 120 才能放两个技能。」

## 节奏挂在对面补刀帧

- 对面 AD 抬手补刀 → 交技能，命中率最高。
- 对面辅助抬手排眼 → 这是最好的先手帧（他站在固定位置，且注意力在眼上）。
- 炮车兵/后排兵残血瞬间 → 强制对面做选择：补刀还是躲技能。

## 线权换的是先动权

- 有线权 → 可以先进河道、先做视野、先支援打野。
- 没线权 → 只能守塔，什么都慢一步。
- 所以第一波兵**必须一直 A**，不是为了补刀，是为了先到 2 级。

## 打不动就换战场

> 原话：「我们下路压不死对面 → 这把下路就混着吧 → 转变思路去游走。」

连续三轮兵线压不出血量，说明对位本身就是均势/劣势，继续堆投入只会被抓。此时改为：让兵线回推、给 AD 发撤退信号、往中靠。

## 蓝量与装备的联动

出女神之泪/蓝量装的第一理由不是伤害，是**对线期能多放几个技能**。判断依据：这局你需要靠技能频次压人，而不是靠一次爆发。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 蓝空了还在前压 | 无法反打，被一波带走 |
| 技能无目的空放 | 自己进入空窗，对面立刻压 |
| 只消耗不推线 | 永远没有游走窗口 |
| 压不死还硬磨 | 被抓一次，前期投入全废 |
