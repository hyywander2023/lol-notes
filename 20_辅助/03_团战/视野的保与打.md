# 视野的保与打：点眼只是第一步

> 结论：点完眼要围绕它打架——点眼→保眼→打架→拿资源是一条链，眼被排掉等于白点。

## 完整链条

| 环节 | 动作 |
| --- | --- |
| 点眼 | 进攻哪个半区就重点点哪个半区 |
| 保眼 | 对面来排眼就围绕它接团，别让眼白点 |
| 打架 | 人先齐、先手开团的一方赢面大 |
| 拿资源 | 打赢顺势推塔或拿龙/先锋 |

视野是进攻的号角，不是防守的摆设。只点不保，等于给对面送排眼经济。

## 抱团进野区流程

清中线 → 一起进野区 → 一起点眼 → 一起守眼。中间差一步就可能被对面先开团打爆炸。队友回城就等一轮再进，否则眼被排、人被蹲。清中线的目的是让对面没有兵线压力，才能放心进野区。

## 死循环破解

队友死→剩的人不敢进野区→对面有技能→被开→继续死。破解办法只有一个：不要分解动作，严格执行上面的完整流程。
