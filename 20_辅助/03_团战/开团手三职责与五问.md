# 开团手三职责与开团五问

> 结论：开团辅助不只负责开——先手、站前排创造空间、留技能反开三件事都要做，开之前先问五句。

## 三大职责

| 职责 | 要点 |
| --- | --- |
| 先手开团 | 优先开脆皮核心；敌方前排脱节时可先处理前排 |
| 创造空间 | 站在核心前面，用站位告诉后排"这里能输出" |
| 保护核心反开 | 敌方刺客/战士盯我方输出时，留技能挡进场，比先手更重要 |

## 开团前五问

1. 开谁？
2. 队友能不能跟？
3. 敌方其他人离目标近不近？
4. 我方人数够不够？
5. 这波团该不该开？

五问有一个答不上来，就先别开。坏开的典型：敌方坦克旁边站着全队，你把全部控制交给他。

## 最难的不是开

是知道什么时候**不开**。留一手保护核心，往往比一次漂亮先手更值。
