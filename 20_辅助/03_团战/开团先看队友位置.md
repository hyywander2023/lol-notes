# 开团先看队友位置，不只看对面站位

> 结论：开团前先确认队友能不能跟上、伤害够不够；队友没到位就先让位拉扯，别急着开。

## 判断条件

开团不只盯着对面站位，还要看三件事：

| 检查项 | 不满足时的风险 |
| --- | --- |
| 队友位置 | 正面口子人少、没成包抄之势，开到 4 人也打不过 |
| 队友装备 | 正面 C 位装备差，伤害不足照样输 |
| 跟进能力 | 杰、酒桶这类跟进慢的没到位，等于自己先手送 |

## 正确做法

先让出位置，等队伍成包抄之势；有海克斯闪现的开团手（瑞尔、泰坦、牛头）先卡草丛，等队友走到能跟上的位置再开。控抵消的开团也要算进去，别把技能浪费在无效先手上。

## 失败归因

"开到四个人却输了"通常不是开团时机错，是队友位置和伤害没跟上——先判断这两点，再决定开不开。
